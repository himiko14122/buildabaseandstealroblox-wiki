Build a Base and Steal에서 코드를 입력하는 것은 초반 진행 속도를 높이는 가장 빠른 방법이지만, 초보 플레이어들은 코드 입력 메뉴를 찾지 못해 수백 개의 무료 캐시, 무료 뽑기(roll), 독점 펫 보상을 놓치는 경우가 많습니다. 이 가이드에서는 코드 입력창의 정확한 위치, 코드를 올바르게 입력하는 방법, 코드가 작동하지 않을 때 대처법을 설명합니다. 아래 단계를 따라 개발자가 제공하는 모든 무료 보상을 단 1분도 낭비하지 않고 모두 획득해 보세요.

## 코드 입력 메뉴 위치

Build a Base and Steal은 대부분의 초보자가 본능적으로 찾는 스폰 화면이 아닌 메인 메뉴 내부에 코드 입력창을 숨겨두었습니다. 서버에 처음 접속했을 때 뽑기 기계나 건설 메뉴를 클릭하지 마세요. 대신 화면 구석에 있는 **메뉴 버튼**(보통 가로줄 세 개, 톱니바퀴 아이콘 또는 'Codes'라는 단어로 표시됨)을 찾으세요. 해당 버튼을 누르면 Codes(코드), Settings(설정), Leaderboard(리더보드), Help(도움말) 등 여러 탭이 포함된 사이드 패널이 열립니다. Codes 탭에서 모든 활성화된 프로모션 코드를 입력할 수 있습니다.

모바일 기기나 태블릿에서 플레이하는 경우, 메뉴가 화면 상단의 작은 아이콘으로 축소되어 있을 수 있습니다. 한 번 탭하여 메뉴를 확장한 다음, 'Codes'라고 적힌 선물 상자 아이콘을 찾으세요. 로블록스(Roblox) 모바일 인터페이스는 자주 변경되므로, 아이콘 위치가 바뀌었다면 메뉴를 가로로 스크롤하여 찾아보세요. 코드 탭은 항상 존재합니다. 개발자들은 플레이어 참여를 유도하는 라이브 운영 파이프라인의 일부이기 때문에 업데이트 중에도 이 탭을 제거하지 않습니다.

### 코드 탭 로드 확인

Codes 탭을 탭하면 텍스트 입력 필드, 'Redeem'(입력) 버튼, 현재 수령하지 않은 보상을 보여주는 배너가 표시되어야 합니다. 입력 필드가 보이지 않는다면 탭을 잘못 연 것입니다. 메뉴를 닫고 선물 아이콘을 다시 찾아보세요. 코드 탭은 때때로 일일 로그인 보상과 함께 묶여 있으므로 두 가지를 혼동하지 않도록 주의하세요. 일일 로그인 보상은 매일 플레이하면 자동으로 지급되지만, 코드 보상은 텍스트를 수동으로 입력해야 합니다.

## 코드를 올바르게 입력하는 방법

공식 목록에 표시된 그대로 텍스트 필드에 코드를 입력하세요. Build a Base and Steal 코드는 대소문자를 구분하므로 대문자와 소문자를 정확히 맞춰야 합니다. 예를 들어 'FREEPET'으로 작성된 코드는 'freepet'이나 'FreePet'으로 입력하면 작동하지 않습니다. 게임에서 가장 흔하게 발생하는 코드 입력 오류는 대문자 오타, 누락된 숫자, 불필요한 공백 등 단 하나의 잘못된 문자 때문입니다. 활성 코드 목록에서 코드를 복사하여 붙여넣으면 이 문제를 완전히 방지할 수 있지만, 수동으로 입력해야 하는 경우 Redeem 버튼을 누르기 전에 모든 글자를 다시 한번 확인하세요.

코드를 입력한 후 Redeem 버튼을 누릅니다. 코드가 활성화 상태라면 캐시 금액, 무료 뽑기 횟수, 포함된 펫 등 방금 받은 보상이 나열된 확인 배너가 표시됩니다. 보상은 게임 내 지갑과 펫 보관함에 즉시 지급되므로, 게임을 다시 로그인하거나 재시작할 필요가 없습니다. 확인 배너가 나타나지 않는다면 코드가 수락되지 않은 것이므로 문제 해결 단계를 진행해야 합니다(아래 참조).

### 코드가 작동하지 않는 이유

Build a Base and Steal에서 코드 입력이 실패하는 데는 네 가지 일반적인 이유가 있습니다. 첫째, 코드가 만료되었습니다. 개발자는 새 코드를 출시할 때 오래된 코드를 순차적으로 만료시키며, 만료된 코드는 아무런 반응 없이 거부됩니다. 특히 오래된 유튜브 영상이나 스크린샷에서 코드를 찾은 경우, 코드를 입력하기 전에 항상 위키의 활성 코드 목록을 확인하세요. 둘째, 코드를 잘못 입력했습니다. 단 하나의 문자만 틀려도 입력이 무효화됩니다. 셋째, 코드가 지역 제한(Region-locked)되어 있습니다. 일부 프로모션 코드는 라이선스 제한으로 인해 특정 국가에서만 작동합니다. 넷째, 이미 계정에서 사용한 코드입니다. 대부분의 코드는 계정당 한 번만 사용할 수 있으므로 동일한 코드를 두 번 입력하려고 하면 오류가 발생합니다.

코드가 활성화되어 있고 올바르게 입력했음이 확실하다면, 게임을 재시작하고 코드를 다시 입력해 보세요. 로블록스는 때때로 이전 서버 데이터를 캐싱하며, 완전히 새로 접속하면 클라이언트가 개발자의 백엔드에서 최신 코드 목록을 강제로 가져옵니다. 재시작 후에도 코드가 여전히 작동하지 않는다면 커뮤니티 디스코드에 글을 남겨보세요. 개발자나 모더레이터가 코드가 버그 상태인지 또는 제한된 상태인지 명확히 안내해 줄 것입니다.

## 획득할 수 있는 보상 유형

Build a Base and Steal 코드는 일반적으로 네 가지 종류의 보상을 제공합니다. 첫 번째는 **즉시 지급되는 캐시**로, 초보자용 코드의 경우 몇 백 단위에서 플레이어 수 달성 또는 업데이트 출시를 기념하는 마일스톤 코드의 경우 수천 단위에 이릅니다. 두 번째는 **무료 뽑기(rolls)**로, 캐시를 쓰지 않고 뽑기 기계를 거쳐 펫을 얻을 수 있게 해줍니다. 무료 뽑기에는 종종 등급 부스트가 포함되어 있어, '무료 뽑기 5회' 코드는 최소 1개 이상의 희귀(Rare) 등급 이상 펫을 보장할 수도 있습니다. 세 번째 보상은 일반적인 뽑기로는 얻을 수 없는 **독점 펫**으로, 주로 시즌 이벤트나 개발자 파트너십과 관련이 있습니다. 네 번째는 소량의 습격(raid) 또는 방어 보너스를 제공하는 특별 도구와 같은 **치장 아이템 또는 장비**입니다.

캐시 보상은 대규모로 지급하기 가장 쉽기 때문에 가장 흔하지만, 가장 가치 있는 코드는 대개 펫을 포함하고 있습니다. 무료 전설(legendary) 펫을 제공하는 코드는 플레이어의 뽑기 시간을 수십 시간 단축해 줄 수 있으므로, 숙련된 플레이어들은 매 세션을 시작할 때마다 활성 코드 목록을 확인합니다. 저희 코드 페이지를 북마크하고 로그인하기 전에 확인해 보세요. 개발자들은 가끔 라이브 스트리밍이나 주요 게임 내 이벤트 중에 깜짝 코드를 배포하며, 이러한 코드는 대개 24시간 이내에 만료됩니다.

### 코드를 일일 로그인 보상과 결합하기

많은 플레이어가 일일 로그인 보상을 수령한 직후 활성화된 모든 코드를 입력하는 것을 습관화하고 있습니다. 이 순서는 복리 효과를 극대화합니다. 일일 캐시가 뽑기 예산을 늘려주고, 코드 보상이 그 위에 캐시를 더해주며, 하루의 첫 뽑기 세션이 두 가지 중 하나만 수령했을 때보다 훨씬 더 생산적이게 됩니다.

최적의 로그인 순서는 간단합니다. 첫째, 서버에 접속합니다. 둘째, 팝업창에서 일일 로그인 보상을 받습니다. 셋째, 메뉴를 열고 Codes 탭으로 이동하여 모든 활성 코드를 입력합니다. 넷째, 다른 작업을 하기 전에 누적된 캐시와 뽑기 횟수를 가지고 뽑기 기계로 갑니다. 이 순서대로 진행하면 코드에서 얻은 무료 뽑기가 세션 시작 시점에 즉시 사용되어, 가장 신선한 뽑기 풀에서 높은 등급의 펫을 뽑을 확률이 가장 높아집니다.

## 코드 탐색을 위한 모범 사례

개발자들은 여러 채널을 통해 새 코드를 출시하며, 어디를 찾아봐야 할지 알면 단 하나의 출처만 확인하는 플레이어보다 확실한 우위를 점할 수 있습니다. 공식 **디스코드(Discord) 서버**는 개발자가 새 코드를 가장 먼저 게시하고 코드가 출시된 배경 설명도 함께 제공하는 경우가 많아 가장 신뢰할 수 있는 출처입니다. 공식 **X / 트위터(Twitter) 계정**은 두 번째로 빠르며, 특히 실시간으로 코드가 배포되는 라이브 이벤트 중에 유용합니다. Build a Base and Steal을 전문으로 다루는 **유튜브 크리에이터**들은 크리에이터 파트너십을 통해 코드를 조기에 제공받는 경우가 많으므로, 이들 중 몇 명을 구독해 두면 남들보다 앞서 나갈 수 있습니다. 마지막으로, 저희 위키는 이 모든 출처의 코드를 취합하여 지속적으로 업데이트되는 목록을 유지하므로, 여러 플랫폼의 공지사항을 쫓아다닐 필요 없이 단 하나의 페이지에서 편리하게 확인할 수 있습니다.

비공식 출처에서 제공하는 코드는 피하세요. 무작위 웹사이트, 클릭 유도용(어그로) 영상, 수상한 디스코드 봇 등은 트래픽을 유도하기 위해 가짜 코드나 만료된 코드를 게시하는 경우가 많습니다. 가짜 코드를 입력하는 것은 시간 낭비일 뿐만 아니라, 의심스러운 링크를 클릭하면 로블록스 계정이 해킹당할 위험이 있습니다. 공식 채널과 저희 위키의 검증된 목록만 확인하면 존재하지도 않는 코드를 쫓아다니며 세션을 낭비하는 일을 방지할 수 있습니다.

### 코드 알림 설정하기

Build a Base and Steal을 경쟁적으로 플레이한다면 공식 디스코드와 X 계정의 알림을 켜두세요. 대부분의 코드 배포는 시간 제한이 있으므로, 새 코드가 출시되는 즉시 알림을 받는 것이 무료 전설 펫을 획득하느냐 놓치느냐의 차이를 만들 수 있습니다. 디스코드의 '멘션(Mentions)' 알림 설정을 해두면 공지 채널에 게시되는 코드를 절대 놓치지 않을 수 있으며, 공식 계정에 대한 X의 알림 필터는 알고리즘 변경으로 인해 새 게시물이 피드에서 숨겨지는 것을 방지해 줍니다.

휴대폰을 자주 확인할 수 없는 플레이어라면 코드 알림 커뮤니티에 가입하거나 신뢰할 수 있는 친구에게 새 코드를 전달해 달라고 부탁하는 것을 고려해 보세요. 일부 커뮤니티에서 운영하는 봇은 공식 출처를 스크랩하여 전용 채널에 코드를 재게시하며, 때로는 타임스탬프와 예상 만료 시간도 함께 제공합니다. 이러한 도구는 공식적으로 보증된 것은 아니지만, 모든 소셜 채널을 수동으로 모니터링하지 않고도 최대한 많은 코드를 챙기고 싶은 플레이어에게 유용합니다.

## 코드 보상 활용 방법

코드를 입력하고 나면 보상을 어떻게 소비할지가 관건입니다. 대부분의 플레이어는 본능적으로 뽑기 기계로 달려가지만, 이것이 항상 최선은 아닙니다. 주로 캐시를 받았다면 일부를 기지 방어에 먼저 할당한 다음 뽑기를 진행하는 것을 고려해 보세요. 5,000 캐시를 주는 코드의 경우, 5,000 캐시 전체를 일반 등급만 나올 수도 있는 뽑기에 쓰는 것보다 2,000 캐시를 벽이나 함정에 투자하는 것이 더 가치 있습니다. 단, 무료 뽑기는 예외입니다. 무료 뽑기는 순수한 보너스이며 모아둔다고 해서 가치가 올라가지 않으므로 항상 즉시 사용하는 것이 좋습니다.

독점 펫을 획득했다면 즉시 가장 높은 등급의 보관함에 보관하세요. 코드로 얻은 독점 펫은 대개 희귀도가 높아 거래 제안을 유도하기에 아주 좋지만, 동시에 습격자들의 표적이 되기도 쉽습니다. 기지를 안정화할 때까지는 새 펫을 가장 강력한 방어벽 뒤에 보관한 다음, 소장할지, 거래할지, 아니면 전시할지 결정하세요. 많은 숙련된 플레이어들은 감성적 가치와 거래 가치 때문에 기지의 가장 깊숙한 금고를 코드 독점 펫 전용으로 비워둡니다.

## 코드 입력에 관한 자주 묻는 질문

**코드는 만료되나요?** 네, 대부분의 코드는 출시 후 며칠에서 몇 주 이내에 만료됩니다. 입력하기 전에 항상 활성 목록을 확인하세요.

**코드를 여러 번 입력할 수 있나요?** 아니요, 코드는 계정당 한 번만 사용할 수 있습니다. 동일한 코드를 두 번 입력하려고 하면 오류가 발생합니다.

**개인 서버에서도 코드가 작동하나요?** 일반적으로 작동하지만, 일부 이벤트 전용 코드는 공용 서버에서만 작동합니다. 개인 서버에서 코드가 작동하지 않는다면 공용 서버에서 시도해 보세요.

**코드를 놓치면 어떻게 되나요?** 놓친 코드는 재발급할 수 없습니다. 개발자가 기념일 이벤트 중에 인기 있었던 코드를 다시 제공하기도 하지만, 이는 보장되지 않습니다.

**코드가 지역 제한되어 있나요?** 일부 코드는 그렇습니다. 코드가 작동하지 않고 출처에서 활성 상태임이 확인되었다면, 지원되지 않는 지역에 계실 수 있습니다.

이 가이드의 단계를 따르면 Build a Base and Steal의 무료 보상을 절대 놓치지 않을 것입니다. 활성 코드 페이지를 북마크하고, 매 세션을 시작할 때마다 코드를 입력하고, 보상을 현명하게 소비하여 기지를 안전하게 지키면서 게임 진행 속도를 높여보세요.

## 자주 묻는 질문

### 세션당 코드 입력 가이드에 어느 정도의 캐시를 배정해야 하나요?

일일 수입의 20~30%를 코드 입력 가이드에 할당하세요. 이러한 통찰력은 라이트 유저와 열성적인 하드 유저를 구분 짓는 요소이며, 매월 리더보드가 초기화될 때마다 동일한 이름이 상위권에 계속 나타나는 것에서 명확히 확인할 수 있습니다.

### 초보 플레이어에게 가장 중요한 코드 입력 가이드 개념은 무엇인가요?

핵심 아이디어는 코드 입력 가이드가 독립적인 활동이 아니라 게임의 나머지 부분과 서로 연결되어 있다는 점입니다. 결정을 내릴 때 이 원칙을 염두에 두면, 원칙이 선택지 간의 결정을 내리는 프레임워크를 제공하므로 이 가이드의 코드 입력 가이드 내용을 실전에 적용하기가 훨씬 더 쉬워질 것입니다.

### 이 전략의 효과를 보려면 얼마나 걸리나요?

일반적인 플레이어는 집중적인 코드 입력 가이드 작업을 시작한 지 약 10일 후에 첫 결과를 보게 됩니다. 가장 활발하게 활동하는 플레이어들은 모두 각자의 경험을 통해 동일한 결론에 도달했기 때문에, 디스코드의 진지한 코드 입력 가이드 토론에서도 이 원칙이 항상 언급되는 것을 볼 수 있습니다.

### 이 전략은 솔로 플레이어와 팀 플레이어 모두에게 유효한가요?

솔로 플레이와 팀 플레이 모두 원칙은 동일합니다. 패치가 거듭되고 구체적인 수치가 바뀌더라도 이 원칙은 변함없이 유지되므로, 나중에 다시 깨닫기보다는 지금 미리 내재화해 두는 것이 좋습니다.

### 패치 이후 전략이 작동하지 않으면 어떻게 해야 하나요?

패치 노트를 자세히 읽고 코드 입력 가이드 시스템의 변경 사항을 확인하세요. 이는 패치 노트에는 직접 나타나지 않지만, 누가 월간 리더보드에 이름을 올리고 누가 그러지 못할지를 결정하는 중요한 통찰력입니다.
