Build a Base and Stealにおける拠点の場所選びは、ゲーム内で最も過小評価されている戦略的決定の1つです。多くのプレイヤーはスポーン地点に基づいて区画を選びますが、それは常に襲撃者の標的となるトラフィックの多いエリアに拠点を構えることを意味します。意図的に区画を選ぶプレイヤーは、トラフィックが少なく、いつどのように襲撃されるかをコントロールしやすいエリアを確保できます。このガイドでは、利用可能な区画のタイプ、各区画の防御力に影響を与える要因、そしてあなたのプレイスタイルに合った区画を選ぶための戦略について解説します。

## 区画のタイプ

Build a Base and Stealのゲームワールドにはいくつかの区画タイプがあり、それぞれ視認性、防御力、リソースへのアクセスに影響を与える異なる特徴を持っています。区画タイプは、中央のスポーンエリアからの距離、地形、およびサイズによって分類されます。

中央区画は、スポーン地点に最も近い区画です。中央区画は視認性が最も高いため、最も襲撃されやすいですが、ローリングマシン、ギアショップ、トレーディングハブへのアクセスが最も容易です。中央区画は、コミュニティで活発に活動したいプレイヤーや、頻繁な襲撃を気にしないプレイヤーに最適です。

エッジ（端）区画は、マップの外周にある区画です。エッジ区画は視認性が低いため、襲撃される頻度は少なくなりますが、中央の施設からは遠くなります。エッジ区画では、ローリングマシンやショップに行くために歩く距離が長くなり、プレイセッションごとに数分余計にかかります。エッジ区画は、不便さを受け入れてでも静かなプレイ体験を求めるプレイヤーに最適です。

コーナー（角）区画は、2つの端が交わるマップの隅にある区画です。コーナー区画はすべての区画タイプの中で最も視認性が低く、最も襲撃されにくい場所です。デメリットは、中央の施設から最も遠く、ローリングマシンまで歩くのに数分かかることです。コーナー区画は、すでにコレクションを確立し、防御とオフラインでの蓄積に集中したいプレイヤーに最適です。

隠し区画は、主要な経路からは見えない区画です。隠し区画は、地形の陰やメインマップの一部ではないエリアにひっそりと存在しています。隠し区画は最も希少で、最も人気があります。なぜなら、最も襲撃されにくいからです。デメリットは、隠し区画を見つけるのが最も難しく、開発者がマップのバランスを維持するためにアップデートで削除することがある点です。

### 視認性要因

視認性は、区画選びにおいて最も重要な単一の要因です。なぜなら、視認性は襲撃頻度に直接影響するからです。主要な経路から見える区画は、通りかかるすべてのプレイヤーの目に留まり、その多くのプレイヤーが襲撃を検討することになります。主要な経路から隠れている区画は、ほとんど誰の目にも留まらず、襲撃されることは滅多にありません。

視認性要因は一定ではありません。ゲーム内の時間帯、開催中のイベント、現在のプレイヤー人口によって変化します。イベント中は、より多くのプレイヤーが活動するため、すべての区画の視認性が高まります。閑散期には、オンラインのプレイヤーが少なくなるため、すべての区画の視認性が低下します。閑散期には隠れていた区画がイベント中には見つかることもありますし、閑散期に見えている区画はイベント中には間違いなく見つかります。

視認性要因は、拠点のデザインによっても影響を受けます。高い壁、明るい色、または特徴的な外観を持つ拠点は、地形に溶け込んでいる拠点よりも目立ちます。視認性を最小限に抑えたいプレイヤーは、自然なカモフラージュがある区画を選び、目立たない拠点を構築すべきです。視認性を最大化したいプレイヤー（取引やソーシャルな目的など）は、中央の区画を選び、目立つ拠点を構築すべきです。

### 地形要因

区画の地形は拠点の防御力に影響します。平坦な区画は建設が容易ですが、自然な防御機能はありません。高低差のある区画は建設が難しくなりますが、襲撃者が下から接近しなければならないため、自然な防御上の優位性が得られます。水やその他の自然の障壁がある区画は、襲撃者が接近できる方向が制限されるため、さらに防御しやすくなります。

地形要因は、完全に防御的な拠点を構築するリソースがない初心者プレイヤーにとって最も重要です。平坦な区画にいる初心者は、基本的な防御力を得るために壁やトラップにキャッシュを費やす必要があります。高低差のある区画にいる初心者は、地形が最初の防御層となるため、ある程度の防御力を無料で得られます。高低差のある区画にいる初心者は、限られたキャッシュをより高ティアの壁やトラップに使えるため、拠点全体の防御力を高めることができます。

地形要因は、地形に関係なく完全に防御的な拠点を構築するリソースを持っている経験豊富なプレイヤーにとってはそれほど重要ではありません。経験豊富なプレイヤーは、建設によって地形の不利を補えることを知っているため、他の要因に基づいて区画を選択します。

### リソースアクセスの要因

中央の施設（ローリングマシン、ギアショップ、トレーディングハブ）への近さは、プレイセッションの効率に影響します。中央区画のプレイヤーは、区画を離れることなくロール、買い物、取引を行うことができ、セッションごとに数分を節約できます。コーナー区画のプレイヤーは、施設に到達するために数分間歩く必要があり、毎回のセッションに時間が追加されます。

リソースアクセスの要因は、施設を頻繁に利用するアクティブなプレイヤーにとって最も重要です。1日に4時間プレイするプレイヤーは、1日に30分プレイするプレイヤーよりも、区画と施設の間を歩くことに大幅に多くの時間を費やすことになります。アクティブなプレイヤーは、歩く時間を最小限に抑えるために中央または中央に近い区画を選ぶべきですが、カジュアルプレイヤーは大きな時間的コストをかけずに、より離れた区画を選ぶことができます。

リソースアクセスの要因は、特定の進行レベルでアンロックされるテレポート機能によっても影響を受けます。テレポート機能を使用すると、区画の場所に関係なく、任意の施設に即座に移動できます。テレポート機能により、歩く時間がなくなるため、リソースアクセスのための区画の場所の重要性は低くなります。テレポート機能をアンロックしたプレイヤーは、リソースアクセスが制約にならなくなったことを踏まえ、他の要因に基づいて区画を選択できます。

### ソーシャル要因

区画の場所は、ソーシャルな体験にも影響を与えます。中央区画はコミュニティの真ん中に位置するため、他のプレイヤーと頻繁に遭遇し、彼らの拠点を目にし、取引やチャットなどのソーシャル活動に参加することになります。コーナー区画は孤立しているため、他のプレイヤーを見かけることは滅多になく、ソーシャルな交流は減りますが、気が散ることも少なくなります。

ソーシャル要因は、Build a Base and Stealのコミュニティ要素を楽しむプレイヤーにとって最も重要です。頻繁に取引を行ったり、Discordの襲撃に参加したり、コミュニティイベントに参加したりするプレイヤーは、ソーシャル活動の近くにいるために中央区画を選ぶべきです。ソロプレイを好むプレイヤーは、気が散るのを避けるために、より孤立した区画を選ぶべきです。

ソーシャル要因は、区画の場所に関係なく利用できるゲーム内チャットによっても影響を受けます。ソーシャルな交流を求めるプレイヤーは、コーナー区画にいてもチャットを使って他のプレイヤーと話すことができます。チャットは対面での交流ほど豊かではありませんが、区画の場所に関係なくコミュニティに関わることができます。

## 適切な区画の選択

適切な区画は、あなたのプレイスタイルと目標によって異なります。初心者プレイヤーには、適度な視認性を持つ中央に近い区画が推奨されます。初心者はある程度のソーシャルな交流や襲撃アクティビティを求めつつも、通りかかるすべてのプレイヤーの標的になることは避けたいと考えます。中央に近い区画はそのバランスを提供します。

中盤のプレイヤーには、適度な地形特徴を持つ中距離の区画が推奨されます。中盤のプレイヤーは防衛する価値のある拠点を構築しており、コミュニティから孤立することなく防御力を得られる区画を求めています。高低差や自然の障壁がある中距離の区画が理想的です。

終盤のプレイヤーには、強力な地形特徴を持つ隠し区画が推奨されます。終盤のプレイヤーは大規模で価値のあるコレクションを所有しており、襲撃頻度を最小限に抑えたいと考えています。自然の障壁がある隠し区画が最も防御力の高い選択肢であり、終盤のプレイヤーは施設から遠いという不便さを受け入れる余裕があります。

## 区画の移転

ゲーム開始時に選択した区画は永続的なものではありません。ほとんどのサーバーでは、通常は拠点のサイズに基づいたキャッシュを支払うことで、新しい区画に拠点を移転できます。移転コストは高額ですが、新しい区画が有意義な戦略的優位性を提供する場合には正当化されます。

区画の移転は、プレイヤーが新しい進行のマイルストーンに達したときによく行われます。中央区画から始めた初心者は、価値のあるコレクションを構築した後に、より良い保護が必要になるため、エッジ区画に移転することがあります。エッジ区画から始めた中盤のプレイヤーは、レジェンダリーのペットを獲得した後に、利用可能な最善の保護が必要になるため、隠し区画に移転することがあります。

移転には時間がかかり、移行中に拠点が無防備になる可能性があるため、慎重に計画する必要があります。拠点は古い区画で解体し、新しい区画で再組み立てする必要があり、これには時間がかかります。移転は、他のプレイヤーが解体された拠点を襲撃しにくい閑散期に行うべきであり、移転コストをカバーするためのキャッシュの蓄えを用意して行うべきです。
