Build a Base and Stealの経済システムは一見するよりも複雑であり、コードシステムは最も誤解されやすい機能の一つです。このFAQでは、キャッシュ、コード、プレミアムパス、そしてゲームを動かす広範な経済システムについて、プレイヤーから最も多く寄せられる質問をまとめました。Robuxを使うべきかどうか、あるいは収入を最大化する方法を知りたい場合、以下の回答が正しい方向性を示してくれるはずです。

## Build a Base and Stealの主要通貨は何ですか？

主要通貨はキャッシュで、ペットの収入、レイド、コード、イベント報酬を通じて獲得できます。キャッシュは壁、トラップ、装備、ペットストレージ、および一部のプレミアムアイテムの購入に使用されます。キャッシュの保有上限はありませんが、イベントや特定のレイドで活用されます。ジェムは限定ペット、プレミアムストレージティア、プレミアムパスの購入に使用されます。ジェムは非常に貴重なため、キャッシュで代用できるアイテムに使うのではなく、ジェムでしか購入できないアイテムのために取っておくのが賢明です。

### Robuxでキャッシュを購入できますか？

はい、可能ですが、交換レートはあまり良くありません。ゲーム内ではRobuxをキャッシュに変換できますが、レートはおよそ1 Robuxあたり100キャッシュです。一方で、同じキャッシュはペットの収入を通じて、所持しているペット次第で1分間に数百から数千キャッシュほど受動的に稼ぐことができます。賢いプレイは、Robuxでキャッシュを買わないことです。変換レートが悪すぎるため、そのRobuxはプレミアムパスやジェム限定アイテムに使う方がはるかに価値があります。

開発者がRobuxからキャッシュへの変換レートを意図的に悪くしているのは、このゲームの経済が直接購入ではなく、アクティブなプレイとパッシブなプレイに報いるように設計されているからです。Robuxで強引にトップを目指そうとするプレイヤーは、同じ時間をかけてガチャや拠点構築に投資したプレイヤーにすぐに追い抜かれてしまうことに気づくでしょう。

## コードはどのように機能しますか？

Build a Base and Stealのコードは、公式Discord、公式Xアカウント、YouTubeクリエイターとのパートナーシップ、アップデート開始イベントなどを通じて配布される短い文字列で、入力すると無料の報酬が得られます。

各コードには、アカウントごとではなく、全プレイヤーベース全体での合計使用回数に制限があります。最も人気のあるコード（ローンチコードなど）は、5万〜10万人のプレイヤーが使用すると上限に達します。あまり人気のないコードは、特定のクリエイターの視聴者に限定されている場合など、数日間使われないこともあります。コードを確実に手に入れる最速の方法は、公開されてから数時間以内に使用することです。

### 新しいコードはどこで見つけられますか？

新しいコードを探すのに最適な場所は、公式Discord、公式Xアカウント、そしてBuild a Base and StealのサブRedditです。Wikiでは毎日更新されるアクティブなコードリストが維持されており、最も信頼できる単一の情報源となっています。このゲームを専門とするYouTubeクリエイターも動画説明欄にコードを投稿しており、開発者がライブ配信中にコードを配布することもあります。

非公式のサイトやYouTubeのコメント欄に表示されるコードは、偽物であったり期限切れであったりすることがよくあります。最も一般的な詐欺は、トラフィックを稼ごうとするアグリゲーターサイトが投稿する「本物に見える」が何も起こらないコードです。新しいコードを使用する前に、必ずWikiのアクティブリストと照らし合わせ、怪しいリンクには決してアクセスしないでください。

## プレミアムパスには何が含まれていますか？

プレミアムパスは499 Robuxで購入でき、オフライン収益上限の倍増（8時間から16時間へ）、毎日のキャッシュ支給、限定ペットスキン、ペットの盗難確率50%減少、一部のジェム限定アイテムへのアクセスなど、多くの特典が含まれています。このパスは一度購入すればアカウントの有効期間中ずっと続く買い切り型であり、サブスクリプションではないため、継続的な料金は発生しません。

ほとんどのプレイヤーにとって、このパスは数週間アクティブにプレイすれば元が取れます。オフライン収益上限の倍増だけでも、中盤のプレイヤーにとっては週に約20万〜50万キャッシュの価値があるからです。限定スキンやペット保護は、その核心的な価値に加えて得られるボーナスです。このパスはゲーム内で最も価値のあるRobuxの使い道であり、開発者が唯一積極的に推奨している購入アイテムです。

### 他にRobuxの使い道はありますか？

はい。ゲームには、プレミアムストレージティア（最大500スロット）、限定ペットスキン、季節ごとのバトルパス、一度限りのコスメティックバンドルなど、Robux専用アイテムがいくつか用意されています。これらはプレミアムパスほどコストパフォーマンスは高くありませんが、特定の見た目を目指している場合や、ストレージをすぐに拡張したい場合には検討する価値があります。バトルパスは299 Robuxで、無料ティア（全プレイヤー対象）とプレミアムティア（パス所有者のみ対象）の両方の報酬が含まれています。プレミアムティアにはそのシーズン限定のレジェンダリーペットが含まれているため、キャッシュ報酬が魅力的でなくても、コレクターにとっては購入する価値があります。

## キャッシュをより速く稼ぐには？

キャッシュを最も速く稼ぐ方法は、ペットのラインナップを最大化し、できるだけ多くのファミリーを完成させ、最高のペットをレベルアップし、サーバーイベント中にプレイすることです。これら4つのアクションの相乗効果は、どれか一つだけを行うよりもはるかに強力であり、トッププレイヤーのほとんどは数ヶ月かけてこれらすべてを最適化しています。

次に速い方法はレイドですが、レイドは受動的な収入源ではなく、時間を投資するものです。レイドに成功すれば、3万〜10万キャッシュ相当のペットに加え、直接購入せずに済んだ装備を獲得できます。レイドは、明確なターゲットと装備が揃っている時に最も効率的であり、何か見つかればいいなとサーバーを彷徨っている時は最も効率が悪くなります。

### キャッシュの最適な使い道は何ですか？

新規プレイヤーにとってキャッシュの最適な使い道は、ガチャ（Rolling）、拠点防衛、ストレージ拡張に均等に配分することです。中盤のプレイヤーにとっては、現在の目標を優先します。

プレイヤーが犯す最大のミスは、レジェンダリーを狙ってキャッシュをすべてガチャに注ぎ込むことです。これは最もエキサイティングな使い道ですが、最も効率が悪いです。なぜなら、運良く引けたレジェンダリー1体よりも、その過程で引く数十体のコモンペットの方が価値が低いからです。ガチャ、防衛、ストレージをバランスよく強化していくことが、長期的な成長への道です。

### 戦略的な背景情報

以下では、経験豊富なプレイヤーが上記の戦略を適用する際に考慮する実践的なポイントを探ります。ここでの内容は、コミュニティでの検証、観察されたハイレベルなプレイパターン、およびゲームメカニクス間の相互作用に基づいています。目的は、数百時間のプレイから得られるような状況判断力を、一度で吸収できる数段落に凝縮して提供することです。

真剣なプレイヤーにとっての出発点は、このゲームが単なる時間の投資よりも、意図的で情報に基づいた決断に報いることを理解することです。次の動きを30分かけて考えたプレイヤーは、3時間ランダムにクリックし続けたプレイヤーよりも早く進歩します。なぜなら、Build a Base and Stealは相互に関連するメカニクスのシステムであり、すべてのアクションがシステム全体に波及するからです。ガチャ戦略の変更は拠点に影響し、それが防衛に影響し、レイド収入に影響し、次のガチャ予算に影響します。

二つ目に、FAQの内容はゲームの他の部分とフィードバックループを形成しています。より強力な拠点は防衛の成功につながり、ペットの保持数が増え、オフライン収入が増え、進行が速まり、さらに拠点が強化されます。逆のフィードバックループも同様です。弱い拠点はペットの喪失、進行の遅延、防衛の弱体化を招きます。序盤の決断は、どのループに入るかを決定するため、非常に大きな影響を与えます。

最後に、このゲームは激しさよりも一貫性に報います。毎日30分ログインして計画的にプレイするプレイヤーは、週に一度5時間ログインして目についたことをするプレイヤーよりも早く進歩します。理由は、あらゆる複利システムと同じです。小さく定期的なアクションは時間の経過とともに大きな利益を生み出し、散発的な大きなアクションは、複利効果のない散発的な結果しか生み出しません。

### よくある落とし穴と回避策

Build a Base and StealのFAQエリアにおいて、新規プレイヤーは予測可能な一連のミスを犯しがちです。これらのミスのほとんどは、何度か経験するまで明らかになりません。このセクションでは、最も一般的な落とし穴を挙げ、それぞれの回避策を説明します。

**落とし穴1：オフライン収入を無視する。** 多くのプレイヤーにとってキャッシュの最大の源泉であるにもかかわらず、初心者が最も軽視しがちな要素です。その結果、目標が達成できません。回避策は、オフライン蓄積を最大化するように拠点を設定し、最高のペットをコア保管庫に配置し、拠点が最も強力な状態で意図的にログアウトすることです。

**落とし穴2：コレクションを構築せずにメタペットを追いかける。** 現在のSランクペットは理論上は素晴らしく見えますが、単一のSランクペットを追いかけるのはコストがかかります。その結果、目標が達成できません。回避策は、安定した収入と優れたファミリーボーナスを提供するAランクやBランクのペットのコレクションを構築し、イベントでドロップ率が上がった時にその収入を使ってSランクペットを狙うことです。

**落とし穴3：リソースを分散させすぎる。** 少しガチャをし、少し建築し、少しレイドをするという誘惑です。その結果、目標が達成できません。回避策は、セッション中は一つのエリアに集中し、その後切り替えることです。分散はすべてを同時に行える確立されたプレイヤー向けであり、集中は進行のためのものです。

**落とし穴4：ターゲットなしでガチャを回す。** ランダムに回すとランダムな結果しか得られません。その結果、目標が達成できません。回避策は、ガチャを始める前にターゲットとなるペットやファミリーを決め、予算に達したら止めることです。ランダムなガチャは、強力なコレクションへの最も遅い道です。
