## Build a Base and Stealコードの3つの時代

コードの履歴は、ローンチ期、成長期、成熟期の3つの時代に自然と分けることができます。ローンチ期はリリース後の最初の6ヶ月間を指し、コードの配布頻度は低く、報酬も控えめで、開発者はゲームの安定化に注力していました。成長期は6ヶ月目から18ヶ月目までをカバーしており、コードがアップデートサイクルの一部として定着し、報酬がより豪華になり、開発者がマイルストーンやイベントを祝うためにコードを使用し始めました。成熟期は直近の6ヶ月間を指し、コードは洗練されたコミュニケーションツールとなり、報酬は現在のメタに合わせて調整され、開発者はイベントへの参加など特定のプレイヤー行動を促すためにコードを使用しています。

ローンチ期は主に歴史的な興味の対象です。その期間のコードはとっくに期限切れになっており、引き換えることはできません。成長期のコードもほとんどが期限切れですが、その期間に確立されたパターンは現在のコード戦略に今なお影響を与えています。成熟期のコードは現在有効なプールであり、現在のプレイにおいて重要なものとなります。

### 配布頻度のパターン

コード履歴全体を通じて、新しいコードの平均リリース頻度は月に約4〜6個です。アップデートのリリース時にはこの頻度が急上昇し、新しいコンテンツを祝うために1週間以内に3〜5個のコードが配布されることもあります。静かな月には頻度が下がり、4週間で1〜2個のコードしか配布されないこともあります。また、アニバーサリー、祝日、プレイヤー数のマイルストーンなどの主要なイベントの前後にも頻度が急上昇します。

プレイヤーにとっての意味合いとしては、平均して5〜7日ごとに新しいコードが期待できるということです。静かな時期には間隔が長くなり、アップデート時には短くなります。Wikiは新しいコードが確認されてから数時間以内に有効なコードリストを更新するため、有効なコードのページをブックマークし、毎セッションの開始時にチェックするのが、新しい配布をキャッチする最も効率的な方法です。

### 報酬のパターン

報酬の種類は3つの時代を経て進化してきました。ローンチ期には、ほぼすべてのコードでキャッシュが提供されていました。キャッシュの額は小さく（通常は500〜1,500）、ゲームをプレイしてくれたことへのささやかな感謝の印でした。成長期には、キャッシュに加えて、無料ロール、無料の壁、無料のペットアップグレードなど、報酬の種類が拡大しました。プレイヤーベースの成長に伴い報酬額も増加し、ローンチ期の最大コードは5,000キャッシュ、成長期の最大コードは15,000キャッシュに加えて10回の無料ロールを提供していました。

成熟期の報酬は最も多様です。現在の報酬タイプには、キャッシュ、無料ロール、無料の壁、無料のギア、オフライン収入2倍ブースト、そして時には無料のレジェンダリーペットチケットが含まれます。各報酬タイプの量は現在のメタに合わせて調整されています。つまり、ゲーム内の価格がプレイヤーの進行状況に合わせてスケールアップしているため、2026年の5,000キャッシュのコードは、2024年の2,000キャッシュのコードとほぼ同等の価値になります。

### 新しいコードの予測

新しいコードの最も信頼できる予測因子は、アップデートカレンダーです。メジャーアップデートにはほぼ確実に少なくとも2〜3個のコードが付属しており、通常はアップデートのテーマに関連したもの（v2.4用の「UPDATE24」など）と、プレイヤー数の目標達成に対するマイルストーンコードが1〜2個用意されます。開発者は通常、アップデートが公開されてから数時間以内に公式Discordや公式X（旧Twitter）アカウントでコードを発表し、コードはリリース後2〜4週間有効です。

2番目に信頼できる予測因子は、イベントスケジュールです。期間限定イベントには通常、イベント期間中にボーナス報酬を提供するイベント専用コードが付属します。イベントコードはアップデートコードよりも寿命が短い傾向があり、1週間以内に期限切れになることもあるため、イベントボーナスが欲しいプレイヤーはコードが配布されたらすぐに引き換える必要があります。

3番目の予測因子は、ソーシャルメディアのアクティビティです。開発者はほとんどのコードを公式Xアカウントや公式Discordに投稿しており、これらの投稿は通常、プレイヤーのアクティビティがピークに達する時間帯に合わせられています。両方のアカウントをフォローし、通知をオンにしておくことで、投稿から数分以内にコードを確認できます。一部のコードは特定のプラットフォーム限定であるため、すべてをキャッチするには両方をフォローする必要があります。

## 隠しコード現象

コード履歴の中で最も興味深い部分は、公式発表なしにコードがリリースされる「隠しコード現象」です。これらのコードは通常、ゲームファイルを調査するデータマイナーや、コードの構造のパターンに気づいたプレイヤーによって発見されます。隠しコードは報酬が小さい傾向にありますが、事前告知がなく、コミュニティに発見されるとすぐに期限切れになることが多いため、見つけると興奮します。

Wikiは報告された隠しコードを追跡していますが、発表されたコードに比べて信頼性は低くなります。一部の「隠しコード」は偽物であったり、すでに期限切れであったりすることがあるため、共有する前に必ず有効なリストと照らし合わせて確認してください。有効なリストは新しいコードが確認されてから数時間以内に更新されるため、実際に機能しているコードの信頼できる情報源となります。

## コードルーティンの構築

コードシステムを使用する最も効率的な方法は、毎日のセッションにコードルーティンを組み込むことです。ルーティンは2つのパートで構成されています。セッション開始時に有効なリストをチェックすることと、他のことをする前に新しいコードを引き換えることです。チェックには30秒、引き換えにはさらに30秒かかるため、ルーティン全体で1セッションあたり1分未満で済みます。

ルーティンの2番目のパートは、正しい順序でコードを引き換えることです。一部のコードは、プレイ開始時に有効化するのが最も価値がある時間制限付きのブースト（RELEASE2Xによるオフライン収入2倍など）を提供します。他のコードは、タイミングに関係なく価値のある永続的なアイテムを提供します。賢い順序は、時間制限付きのコードを最初に引き換え、次に永続的なコード、最後にキャッシュコードを引き換えることです。これにより、時間制限付きのブーストをセッションの可能な限り長い時間有効にすることができます。

ルーティンの3番目のパートは、確認されたコードをコミュニティと共有することです。Wikiは新しいコードを特定するためにプレイヤーからの報告に依存しており、コードを早期に報告するプレイヤーはコミュニティ全体を助けることになります。報告には、コード自体、それが提供する報酬、およびそれを見つけたプラットフォームを含める必要があります。Wikiチームは数時間以内に報告を確認し、それに応じて有効なリストを更新します。

コード履歴の細部に飛び込む前に、目に見えるゲームを取り巻くメタゲームを理解する時間を取ってください。目に見えるゲームとは、ロール、建築、レイドのループです。メタゲームとは、パッチサイクル、コミュニティの議論、取引経済、そして長期的な進行アークです。目に見えるゲームは、セッション中の30分間で行うことです。メタゲームは、数週間から数ヶ月にわたって最適化することです。最も成功しているプレイヤーは、両方のゲームを同等に真剣に扱い、真に大きな利益はメタゲームから得られることを理解しています。

コードと取引の関係は、新しいプレイヤーに見落とされがちです。あなたが行う取引は、ベース、防御、そしてロールの選択肢に影響を与えます。ベースに最適なペットは、取引資産としてより価値があるかもしれません。あなたが弱いと思うペットが、別のプレイヤーのコレクションボーナスの欠けているピースであり、そのためプレミアム価値がつくかもしれません。取引のマインドセットはポートフォリオ思考です。すべてのペットは個人的な資産であると同時に潜在的な取引チップであり、その価値はより広い市場の文脈に依存します。

3つ目は、メタはパッチごとに変化し、先月機能していた戦略が今月は最適ではない可能性があるということです。最も回復力のあるプレイヤーは、特定のペットのランキングや壁のレイアウトを暗記するプレイヤーではなく、基礎となるメカニズムを深く理解しているプレイヤーです。メタが変化したとき、メカニズムを理解しているプレイヤーは1日で戦略を適応させることができます。古い戦略を暗記していたプレイヤーは、すべてを学び直さなければなりません。
