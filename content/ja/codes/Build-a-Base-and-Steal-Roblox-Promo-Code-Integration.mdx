## コードシステムに関するよくある誤解

最も一般的な誤解は、Build a Base and StealのコードをRobloxのウェブサイトで引き換えられる、あるいはその逆ができるというものです。これらはできません。2つのシステムは別個のものであり、コードはそれぞれの引き換えインターフェースでのみ機能します。Build a Base and StealのコードをRobloxのウェブサイトで引き換えようとするとエラーになり、RobloxプロモーションコードをBuild a Base and Stealで引き換えようとしてもエラーになります。

2つ目の誤解は、すべてのゲーム内コードがすべてのサーバーで機能するというものです。一部のコードは特定のサーバー（通常はコンテンツクリエイターに関連付けられたプライベートサーバー）に限定されており、別のサーバーで引き換えようとするとエラーになります。Wikiにはサーバー限定のコードが記載されているため、引き換える前に有効なリストを確認してください。

3つ目の誤解は、コードを重ねてより大きな報酬を得られるというものです。これはできません。各コードは固定の報酬を与えるものであり、同じコードを2回引き換えても報酬は蓄積されません。すでに引き換えたコードを再度入力しようとすると、引き換えインターフェースは「すでに引き換え済み」というエラーを返します。

## よくある質問

### この戦略はソロプレイヤーとチームプレイヤーの両方に有効ですか？

ソロプレイヤーもチームプレイヤーも、この戦略を使用できます。この考え方を内面化したプレイヤーは、特定の行動を暗記することに集中するプレイヤーよりも早く進行する傾向があります。なぜなら、基礎となる原則は変化するメタに適応する一方で、特定の行動はパッチごとに古くなってしまうからです。

### このトピックに関する詳細情報はどこで入手できますか？

### Robloxプロモーションコードはトレード経済とどのように相互作用しますか？

トレード経済とRobloxプロモーションコードは常に相互作用しています。Robloxプロモーションコードの成果はトレードに供給されます。この原則を自動的に適用することを学んだプレイヤーは、すべての決定を意識的に考える必要があるプレイヤーよりも30〜50%早く進行する傾向があります。なぜなら、この原則がすべての行動における熟考フェーズをショートカットするからです。

### Robloxプロモーションコードに集中するのに最適な時間帯はいつですか？

夜間や週末は最もアクティブなプレイヤーが多いですが、最適な時間はあなたのスケジュール次第です。これはパッチノートには載らないような洞察ですが、誰が月間リーダーボードに載り、誰が載らないかを決定づける要因となります。
