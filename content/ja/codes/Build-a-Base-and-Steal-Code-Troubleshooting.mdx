コードの引き換えは、Build a Base and Stealにおいて最もシンプルな作業であるはずです。コードを入力し、引き換えボタンをクリックすれば、報酬を受け取ることができます。しかし実際には、引き換えプロセスはプレイヤーの不満の最も一般的な原因の一つとなっています。なぜなら、失敗する原因がいくつかあり、表示されるエラーメッセージが必ずしも役に立つとは限らないからです。このガイドでは、コードの引き換えに失敗する一般的な原因、実際の原因を特定するための診断手順、およびほとんどの場合にコードを機能させるための回避策について解説します。

## 引き換えインターフェース

Build a Base and Stealのコード引き換えインターフェースは、メインメニューから通常「Codes（コード）」または「Promo Codes（プロモコード）」ボタンをクリックすることでアクセスできます。インターフェースには、テキスト入力フィールド、「Redeem（引き換え）」ボタン、および過去に引き換えたコードの履歴が表示されます。コードを引き換えるには、入力フィールドにコードを入力または貼り付け、「Redeem」をクリックします。報酬は数秒以内にウォレットまたはストレージに反映され、確認メッセージが表示されます。

一部のプラットフォームでは、インターフェースに「クリップボードからコピー」ボタンがあり、現在のクリップボードの内容を入力フィールドに貼り付けることができます。これは、WikiやDiscordのメッセージからコピーしたコードを使用する際に便利で、手動入力によるタイポ（打ち間違い）を防ぐことができます。引き換えエラーのほとんどはタイポが原因であるため、コピーボタンを使用するのが最も簡単な回避方法です。

### 原因1：コードの有効期限が切れている

コードの引き換えに失敗する最も一般的な原因は、コードの有効期限が切れていることです。Build a Base and Stealのすべてのコードには有効期間（コードを引き換えることができる期間）があります。有効期間はコードによって異なり、永続的なものもあれば、数週間有効なもの、数日間しか有効でないものもあります。有効期間が終了すると、コードはライブサーバーから削除され、引き換えインターフェースは「無効なコード」エラーを返します。

解決策は、引き換えを試みる前に、Wikiの有効なコードリストでコードを確認することです。有効なリストには現在機能しているすべてのコードが表示され、期限切れのコードは期限切れリストに移動されます。引き換えようとしているコードが有効なリストにない場合、そのコードは期限切れであり、どのようなトラブルシューティングを行っても機能しません。

### 原因2：コードにタイポ（打ち間違い）がある

コードが機能しない2番目に多い原因は、手動入力時のタイポです。Build a Base and Stealのコードは文字の大小を区別します。つまり、「STEAL2026」は「steal2026」や「Steal2026」とは異なるコードとして扱われます。また、コードには、数字の「1」と小文字の「l」、数字の「0」と大文字の「O」、数字の「5」と大文字の「S」など、見た目が似ている異なる文字が使われていることがあります。これらの文字を1つでも打ち間違えると、引き換えは失敗します。

解決策は、コードを手動で入力するのではなく、コピーボタンを使用することです。手動で入力する必要がある場合は、ソースと照らし合わせて各文字を再確認してください。Wikiでは、似た文字を区別しやすいように等幅フォント（monospace）でコードが表示されているため、スクリーンショットやチャットメッセージからコピーするよりも、Wikiからコピーする方が確実です。

### 原因3：コードが地域制限（リージョンロック）されている

Build a Base and Stealのコードの一部は地域制限されており、特定の地理的地域でのみ有効です。地域制限されたコードは通常、地域のイベントや地域のコンテンツクリエイターとのパートナーシップに関連付けられており、サポート対象外の地域から引き換えようとすると「無効なコード」エラーが返されます。

解決策は、Wikiのコードの説明または公式発表を確認することです。コードが地域制限されている場合、通常はその説明に地域が指定されています。サポートされている地域外にいる場合、回避策はありません。同様の報酬を獲得するには、グローバルコードがリリースされるのを待つ必要があります。

### 原因4：コードに最低レベル要件がある

一部のコードは、引き換えるアカウントが最低レベルに達していることを要求します。レベル要件は通常、報酬の内容に関連しており、高ティアの報酬ほど高いレベルが必要になります。レベル1のアカウントでレジェンダリーティアのコードを引き換えようとすると、「レベルが低すぎます」というエラーが返され、引き換えに失敗します。

解決策は、アカウントのレベルを上げてから再試行することです。レベル要件は通常、数日間のプレイで達成できるため、ほとんどのプレイヤーは開始から1週間以内に要件を満たすことができます。Wikiでは、判明しているレベル要件を記載しているため、有効なコードリストで最低レベルの注記を確認してください。

### 原因5：コードサーバーがダウンしている

Build a Base and Stealのコード引き換えは、メインのゲームサーバーとは別のバックエンドで実行されており、この引き換えバックエンドはメンテナンスのために一時的にダウンすることがあります。バックエンドがダウンしている場合、引き換えインターフェースは「サービス利用不可」エラーを返し、バックエンドが復旧するまでコードを引き換えることはできません。

解決策は、しばらく待ってから再試行することです。バックエンドは通常数時間以内に復旧し、開発者は公式SNSで障害を発表することが一般的です。Wikiでもバックエンドがダウンしているかどうかを記載するため、さらにトラブルシューティングを行う前に、有効なコードページでサービスに関するお知らせを確認してください。

## 原因6：コードがすでに引き換えられている

一部のコードはアカウントごとに1回のみ使用可能で、一度引き換えると二度と引き換えることはできません。すでに受け取ったコードを再度引き換えようとすると、引き換えインターフェースは「すでに引き換え済み」エラーを返します。これは意図された仕様であり、バグではありません。

解決策は、コードインターフェースの引き換え履歴を確認することです。履歴にはこれまでに引き換えたすべてのコードが表示されるため、すでにそのコードを受け取っているかどうかを確認できます。履歴にコードがある場合、それは引き換え済みであり、エラー表示は正しいことになります。

## 原因7：プライベートサーバーからのコードである

Build a Base and Stealのコードはグローバルであり、すべてのパブリックサーバーで機能するはずです。しかし、一部のプライベートサーバーではコードリストが古く、パブリックサーバーで機能するコードがそれらのプライベートサーバーではエラーになることがあります。これはプライベートサーバーのインフラにおける既知の問題であり、開発者はまだ完全に解決していません。

解決策は、パブリックサーバーでコードを引き換えることです。普段プライベートサーバーでプレイしている場合は、一度ログアウトしてパブリックサーバーに参加し、コードを引き換えてからプライベートサーバーに戻ってください。パブリックサーバーで引き換えたコードはアカウントに永続的に追加されるため、この作業はコードごとに1回行うだけで済みます。

## 高度なトラブルシューティング手順

上記の理由のいずれにも当てはまらない場合、問題を解決できる可能性のある高度なトラブルシューティング手順がいくつかあります。

最初のステップは、ゲームを完全に閉じて再起動することです。引き換えエラーの一部はクライアントの状態が古くなっていることが原因であり、完全に再起動することで状態がクリアされます。ゲームを閉じ、30秒待ってからゲームを再起動し、再度引き換えを試みてください。これにより、少数の引き換えエラーが解決します。

2番目のステップは、Robloxの接続を確認することです。Build a Base and StealはRobloxの認証インフラを使用しており、認証の一時的な不具合によって引き換えエラーが発生することがあります。Robloxに正しくログインしていることを確認し、再度引き換えを試みてください。Robloxの接続が原因である場合、接続が復旧すれば引き換えができるようになります。

3番目のステップは、サポートに問い合わせることです。すべてのトラブルシューティング手順を試してもコードが機能しない場合は、ゲーム内のヘルプメニューまたはサポートメールから公式サポートに連絡してください。引き換えようとしているコード、表示されるエラーメッセージ、使用しているプラットフォーム、およびRobloxのユーザー名を記載してください。サポートチームは通常24〜48時間以内に返信し、コードが正当なものであると確認されれば、アカウントに手動で報酬を適用してくれることもあります。
