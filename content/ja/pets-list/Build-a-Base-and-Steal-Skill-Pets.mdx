Build a Base and Stealのすべてのペットが同じように作られているわけではありません。ほとんどのペットは受動的な収入源（パッシブジェネレーター）ですが、「スキルペット」と呼ばれる一部のペットは、基地の機能を変化させる特殊能力を持っています。スキルペットは、隣接するペットの収入を増やしたり、壁を強化したり、侵入者を凍らせたり、ロール（ガチャ）のコストを下げたりすることができます。スキルペットがいない基地と、慎重に選ばれたスキルペットが配置された基地の違いは、単なる受動的な収入源と、自己増殖する能動的なエンジンの違いのようなものです。このガイドでは、スキルシステムを分解し、役割ごとに最適なスキルペットをランク付けし、特定の役割を中心とした編成の組み方を紹介します。

## 3つのスキルカテゴリ

Build a Base and Stealのスキルペットは、攻撃、防御、ユーティリティの3つのカテゴリに分類されます。攻撃型スキルペットは、グローバルボーナスによる直接的な方法、または隣接ボーナスによる間接的な方法で、基地の収入を増加させます。防御型スキルペットは、壁の強化、侵入者の氷結、または敵の装備の効果低減によって基地を守ります。ユーティリティ型スキルペットは、ロール、アップグレード、回復などの他のアクションのコストを削減します。

これらのカテゴリは互いに排他的ではありません。一部のペットは攻撃能力と防御能力の両方を持っています。例えば、コズミックドラゴン（Cosmic Dragon）はトラップダメージに防御ボーナスを提供し、隣接するペットを盗みから守ります。クァンタムリヴァイアサン（Quantum Leviathan）は水タイプのペットに攻撃ボーナスを提供し、基地内のペットの収入をランダムに2倍にします。最高のスキルペットは、複数のカテゴリで恩恵をもたらすことが多く、異なる役割を埋めるために必要なペットの数を減らしつつ、編成の効率を高めることができます。

### スキルの発動方法

Build a Base and Stealのスキルは、パッシブ、定期的、条件付きの3つの方法で発動します。パッシブスキルは、特定のタイプのペットに提供されるオーラボーナスのように、常に有効です。定期的スキルは、クァンタムリヴァイアサンのランダム収入2倍のように、タイマーに基づいて自動的に発動します（5〜10分ごとなど）。条件付きスキルは、フロストサーペント（Frost Serpent）の氷結能力のように、特定のイベントが発生したときに発動します（侵入者が基地に入ったときなど）。

発動タイプによってスキルの効果が決定されます。パッシブスキルは常に有効で効果が予測しやすいため、最も安定しています。定期的スキルは発動のタイミングがランダムであるため安定性に欠けますが、時間経過による平均的な効果は計算可能です。条件付きスキルは条件が満たされたときにしか発動しないため最も不安定ですが、PvPサーバーで襲撃が多い時期など、条件が頻繁に満たされる状況では非常に強力になります。

## 攻撃型スキルペット

### エターナルフェニックス (Eternal Phoenix)
エターナルフェニックスは、現在のメタにおいて最強の攻撃型スキルペットです。そのパッシブ能力は、すべての火タイプペットに10%のオーラボーナスを提供し、火属性テーマの基地にとって強力な乗数となります。その定期的能力は、隣接するペットの収入を30秒間20%増加させ、この能力は2〜3分ごとに発動します。これら2つの能力は重複するため、フェニックスに隣接する火タイプのペットは、10%のオーラボーナスと20%の隣接ボーナスの両方を受け取り、合計で30%の収入増加となります。

フェニックスの定期的能力は隣接関係に基づいて発動するため、最適な配置はフェニックスを最も価値の高い火タイプペットで囲むことです。オーラボーナスは隣接関係に関係なく、基地内のすべての火タイプペットに適用されるため、フェニックスは完全に火属性で統一されていない基地でも価値があります。広いオーラと強力な定期的隣接ボーナスの組み合わせにより、フェニックスはゲーム内で最も用途の広い攻撃型スキルペットとなっています。

### クァンタムリヴァイアサン (Quantum Leviathan)
クァンタムリヴァイアサンは、攻撃型スキルペットの準優秀候補です。そのパッシブ能力は、すべての水タイプペットに15%のオーラボーナスを提供します。これはフェニックスのオーラボーナスよりも強力ですが、範囲が限定されています。その定期的能力は、基地内のペット1匹の収入を60秒間ランダムに2倍にし、この能力は5〜10分ごとに発動します。2倍効果はミシック（Mythic）ペットを含む基地内のどのペットにも発動する可能性があるため、リヴァイアサンはランダムな収入スパイクの強力な源となります。

リヴァイアサンの定期的能力はフェニックスの能力よりも安定性に欠けますが、上振れは大きいです。基本レートが900のミシックペットが2倍になると、60秒間毎秒1800のブーストが発生し、これはかなりの額になります。リヴァイアサンは、変動を楽しみ、大規模なランダムボーナスの可能性を求めるプレイヤーにとって最適な選択肢です。安定性を好むプレイヤーには、フェニックスの方が適しています。

### ソーラーイーグル (Solar Eagle)
ソーラーイーグルは、幸福度（Happiness）に特化した専門的な攻撃型スキルペットです。そのパッシブ能力はすべての光タイプペットの幸福度に10%のボーナスを提供し、その定期的能力は隣接するペットの幸福度を90秒間20%増加させ、3〜4分ごとに発動します。幸福度ボーナスは、幸福度が乗算的な収入補正値であるため価値があり、幸福度を高く保つことで、編成全体の収入を間接的に10〜20%増加させることができます。

イーグルは、毎日手動でペットに餌を与えたりローテーションさせたりする時間がないプレイヤーにとって最適な選択肢です。これらのプレイヤーにとって、イーグルは維持の手間を減らし、アクティブな作業なしで収入を高く維持してくれます。幸福度ボーナスは、編成に多くの光タイプペットを入れているプレイヤーにとっても価値があります。オーラボーナスはすべての光タイプペットに適用され、定期的ボーナスはタイプに関係なく隣接するペットに適用されるためです。

## 防御型スキルペット

### コズミックドラゴン (Cosmic Dragon)
コズミックドラゴンは、現在のメタにおいて最強の防御型スキルペットです。そのパッシブ能力は、半径4タイル以内のすべてのトラップダメージに20%のボーナスを提供し、その条件付き能力は、侵入者が基地に入ったときに隣接するペットを60秒間盗みから無効にします。トラップダメージボーナスは防御をトラップに依存しているプレイヤーにとって価値があり、盗み無効化は最も価値の高いペットを襲撃から守りたいプレイヤーにとって価値があります。

ドラゴンの条件付き能力は侵入者の侵入によって発動するため、襲撃が頻繁に発生するPvPサーバーで最も価値があります。PvEサーバーでは、この能力が発動することはほとんどなく、ドラゴンの実用性は無駄になります。PvPサーバーのプレイヤーにとって、ドラゴンは防御編成の不可欠な一部です。PvEサーバーのプレイヤーにとっては、フロストサーペントのような別の防御ペットの方が良い選択肢となるでしょう。

### フロストサーペント (Frost Serpent)
フロストサーペントは、特化型の防御型スキルペットです。そのパッシブ能力はすべての氷タイプペットに15%のオーラボーナスを提供し、その条件付き能力は半径5タイル以内のすべての侵入者を30秒間凍らせます。凍結能力は、プレイヤーが防御を準備したり増援を呼んだりする時間を与えるため強力であり、また、凍結された侵入者は凍結期間中にペットを盗むことができないため、襲撃の実質的な時間を短縮します。

サーペントの条件付き能力は、ドラゴンの能力と同様に侵入者の侵入によって発動します。サーペントは、PvPサーバーのプレイヤー、特に繰り返し襲撃を受けており、侵入者がペットを盗む前に阻止する方法を必要としているプレイヤーにとって強力な選択肢です。凍結能力は、遅延後に発動するトラップなど、時間差のある防御に頼っているプレイヤーにとっても価値があります。凍結によって遅延が延長され、トラップが作動するまでの時間を稼ぐことができるためです。

### ストーンゴーレム (Stone Golem)
ストーンゴーレムは、耐久力のある防御型スキルペットです。そのパッシブ能力は半径3タイル以内のすべての壁の耐久力に10%のボーナスを提供し、その定期的能力は基地内のすべての壁の耐久力を120秒間20%増加させ、5〜10分ごとに発動します。壁の耐久力ボーナスは、収入よりも基地の防御を優先するプレイヤーにとって価値があります。壁が強化されることで襲撃時の持ち時間が長くなり、プレイヤーが対応する時間をより多く確保できるためです。

ゴーレムの定期的能力はパッシブボーナスほど安定していませんが、時間経過による平均的な効果は大きいです。時間の20%で壁の耐久力が20%増加することは、時間経過による壁の耐久力の平均4%の増加に相当します。壁のアップグレードに多額の投資をしているプレイヤーにとって、ゴーレムは防御の寿命を大幅に延ばすことができます。

## ユーティリティ型スキルペット

### ヴォイドタイガー (Void Tiger)
ヴォイドタイガーは、現在のメタにおいて最強のユーティリティ型スキルペットです。そのパッシブ能力はすべての闇タイプペットに5%のオーラボーナスを提供し、その定期的能力はロールのコストを120秒間10%削減し、10〜15分ごとに発動します。ロールコストの削減はペットの獲得を直接加速させるため価値があり、長時間のロールセッション中に複数の発動が累積することで、かなりの額のキャッシュを節約できます。

タイガーの定期的能力はタイマーで発動するため、最適な戦略は能力のクールダウンに合わせてロールセッションを計画することです。能力が発動しそうになったらロールセッションを開始すれば、セッション全体でロールコストが削減されます。頻繁にロールを行うプレイヤーにとって、タイガーは数週間のプレイで数百万のキャッシュを節約することができます。

### スピリットウルフ (Spirit Wolf)
スピリットウルフは、グローバルなユーティリティ型スキルペットです。そのパッシブ能力はすべてのスピリットタイプペットに5%のオーラボーナスを提供し、その定期的能力は基地内のすべてのペットのレートを60秒間5%増加させ、8〜10分ごとに発動します。グローバルなレート増加は、タイプや隣接関係に関係なく基地内のすべてのペットに適用されるため価値があり、ペットのタイプが多様な編成にとってウルフは強力な選択肢となります。

ウルフの定期的能力は、フェニックスの隣接ボーナスのようなターゲットを絞った能力ほど強力ではありませんが、グローバルに適用されるためより安定しています。ウルフは、収入のわずかなパーセンテージも重要となるゲーム序盤の編成にとって強力な選択肢であり、単一のペットタイプに基地を特化させていない終盤のプレイヤーにとっても価値を持ち続けます。

## スキルペットを中心とした編成の構築

Build a Base and Stealの最適な編成には、それぞれ特定の役割を果たす3〜5匹のスキルペットが含まれます。バランスの取れた構成には、攻撃型スキルペット1匹、防御型スキルペット1匹、ユーティリティ型スキルペット1匹が含まれ、プレイヤーのプレイスタイルやサーバーの状況に基づいてさらに2匹のスキルペットが選択されます。残りのペットスロットは、スキルペットの能力から恩恵を受ける高レートのパッシブペットで埋められます。

PvE重視のサーバーにおける最適な構成は、エターナルフェニックス（攻撃型）、ソーラーイーグル（ユーティリティ）、および3匹の高レートパッシブペットです。フェニックスは収入ボーナスを提供し、イーグルは幸福度ボーナスを提供し、パッシブペットは収入を生成します。襲撃が稀であるため、防御型スキルペットは必要ありません。

PvP重視のサーバーにおける最適な構成は、コズミックドラゴン（防御型）、フロストサーペント（防御型）、ヴォイドタイガー（ユーティリティ）、および2匹の高レートパッシブペットです。ドラゴンとサーペントは襲撃からの保護を提供し、タイガーはロールコストを削減し、パッシブペットは収入を生成します。襲撃が頻繁に発生するため、防御に焦点を当てることが必要です。

### スキルペットの上限

Build a Base and Stealの1つの基地において、有用なスキルペットの数にはソフトキャップ（緩やかな上限）が存在します。スキルペットが5匹を超えると、新しいペットの能力が既存の能力と重複して収穫逓減が発生するため、追加する限界便益は急激に減少します。スキルペットを10匹配置した基地は、5匹配置した基地よりも効率が低下します。スキルペットのスロットが、より多くの収入を生み出すはずの高レートのパッシブペットを押し出してしまうためです。

スキルペットの最適な数は、編成のサイズによって異なります。20匹の編成では3〜4匹のスキルペットが適切です。30匹の編成では4〜5匹のスキルペットが適切です。10匹の編成では2〜3匹のスキルペットが適切です。パッシブペットは主要な収入源であり、スキルペットはその収入をブーストするために存在し、置き換えるためのものではないため、スキルペットとパッシブペットの比率が1:3を超えてはなりません。

スキルペットは、Build a Base and Stealのペットシステムの「深さ」です。パッシブペットは「広さ」です。多くのペットを集めますが、深く投資するのは基地の機能を変化させる少数のスキルペットのみです。スキルペットを慎重に選び、戦略的に配置し、その能力を中心に残りの編成を構築しましょう。
