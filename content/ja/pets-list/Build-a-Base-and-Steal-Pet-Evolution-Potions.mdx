## ペットの進化の仕組み

Build a Base and Stealにおけるペットの進化は、進化素材とキャッシュを消費して、ペットを低いレアリティから高いレアリティへと引き上げる一方通行の変身プロセスです。この変身によってペットの外見、特殊能力、親密度レベルは維持されますが、基本レートが上昇し、より高いステータス上限が解放されます。コモンのペットをアンコモンに進化させると基本レートが約50%上昇し、アンコモンからレアでさらに50%、レアからエピックで50%、エピックからレジェンダリーで50%、レジェンダリーからミシックでさらに50%上昇します。

累積的な効果は非常に大きく、コモンのペットをミシックまで進化させると基本レートは約7.5倍にまで跳ね上がります。これにより、進化は新しいペットをガチャで引くことの有力な代替手段となります。ただし、進化コストは段階が上がるごとに劇的に増加し、ミシックへの最終進化に必要な素材は非常に希少で高価です。素材コストが非常に高いため、何度も繰り返すことは難しく、ほとんどのプレイヤーはキャリアを通じて数体のペットをミシックに進化させるのが精一杯でしょう。

### 進化素材とその入手方法

Build a Base and Stealの進化素材は、コモン素材とレア素材の2つのカテゴリーに分けられます。コモン素材には進化ダスト、シャード、クリスタルがあり、ガチャ、レイド、デイリークエストから入手できます。レア素材には進化エッセンス、コア、スターがあり、高レベルレイド、イベント、ボス戦から入手可能です。レア素材はコモン素材に比べてドロップ率が極めて低いため、進化システムにおけるボトルネックとなります。

レア素材の最も確実な入手源はボス戦システムです。ボスはBuild a Base and Stealのサーバーに定期的に出現し、撃破することでレア素材が確実にドロップします。ドロップする素材の種類はボスによって異なり、火のボスは火属性のエッセンス、水のボスは水属性のエッセンスといった具合です。また、ボス戦はミシックへの最終進化に必要な「進化スター」の唯一の入手源でもあります。ペットを進化させたいプレイヤーは、ボスが出現した際には優先的に挑戦するようにしましょう。

### 進化の判断基準

すべてのペットが進化させる価値があるわけではありません。進化の判断は、まずペットのレアリティと親密度レベルから始まります。親密度レベル1のペットは、まだ十分に愛着や投資ができていないため、進化させるべきではありません。親密度レベル5以上のペットは、これまでレベル上げに費やした時間が投資として維持されるため、進化の有力な候補となります。レアリティが低い（コモンやアンコモン）ペットは、コストがステータス上昇に見合わないため、一般的にエピック以上に進化させる価値はありません。一方、エピックやレジェンダリーなどの高レアリティのペットは、最終進化の限界コストがステータス上昇に対して妥当であるため、ミシックまで進化させる価値があります。

2つ目の考慮事項は、ペットの特殊能力です。「1秒あたりキャッシュ+10」のような固定値ボーナスを与える能力は、ペットの基本レートが上がるにつれて相対的に弱くなります。一方、「隣接するペットの収入+10%」のようなパーセンテージボーナスを与える能力は、基本レートが上がるにつれて相対的に強くなります。進化は基本レートを乗算し、それが能力の効果をさらに乗算するため、パーセンテージベースの能力を持つペットの方が進化に適しています。

## レアリティポーション：効果と使用タイミング

Build a Base and Stealのレアリティポーションは、ポーション以外の素材を消費することなく、ペットを即座に1段階上のレアリティへ進化させる消費アイテムです。レアリティポーションは非常に希少で、通常はイベント、プレミアムショップ、またはボス戦でしか入手できません。コモン以上の5つのレアリティに対応して、アンコモンポーション、レアポーション、エピックポーション、レジェンダリーポーション、ミシックポーションの5種類が存在します。

レアリティポーションの利点は、素材コストと進化のクールダウンをスキップできる点にあり、特にミシックへの最終進化においてその恩恵は絶大です。欠点はポーションが希少であることであり、間違ったペットに使用することは取り返しのつかないミスとなります。レアリティポーションの最適な使い道は、すでに親密度レベルが5以上で、パーセンテージベースの特殊能力を持つペットに使用することです。これらのペットはレアリティ上昇の恩恵を最大限に受けられるため、希少なリソースの価値を最大化できます。

### ポーション vs 通常の進化

レアリティポーションを使うか、通常の進化を行うかは、素材の備蓄状況とスケジュールによって決まります。レア素材が余っており、すぐに使う予定がない場合は、通常の進化が適しています。これにより、素材で進化させることが難しいペットのためにポーションを温存できます。逆に、素材が不足しているものの過去のイベントでポーションを貯めている場合は、ポーションを使うのが賢明です。素材のドロップを待たずに重要なペットをアップグレードできるからです。

一般的なルールは以下の通りです：コモンからアンコモン、アンコモンからレア、レアからエピックへの進化は素材を使用します。エピックからレジェンダリーへの進化は、余裕があれば素材を使い、なければレジェンダリーポーションを使用します。レジェンダリーからミシックへの進化は、ミシックポーションがあればそれを使用し、なければ素材を使用します。ミシックへの最終進化は最も素材を消費するため、ここでポーションを使うのが最もレバレッジの効いた（効率的な）使い方となります。

## 進化させるべきペット

Build a Base and Stealのコミュニティでは、どの進化に投資すべきかについて大まかな合意が形成されています。リストのトップに位置するのは、現在のメタにおけるSランクのペットたちです：エターナル・フェニックス、クォンタム・リヴァイアサン、コズミック・ドラゴン。これらのペットをミシックに進化させることは、ほぼ間違いなく価値があります。これらは元々ゲーム内で最強のペットであり、進化によって競合他社との差をさらに広げることができるからです。進化コストは高いですが、収入面での見返りはそれ以上です。

### 序盤の例外

Bランクの進化に関する一般的なルールには重要な例外があります。序盤において、ロスターが小さく、すべてのペットが収入に大きく貢献している時期には、たとえ終盤で使わなくなるとしても、Bランクのペットをエピックやレジェンダリーに進化させることは正しい判断となり得ます。序盤は機能的なロスターをいかに早く構築するかが重要であり、Bランクの進化はAランクやSランクの代わりをガチャで引くよりも早い場合が多いからです。

この判断の分かれ目は、親密度レベルが7前後、かつロスター内のペット総数が25〜30体程度の時点です。それ以前であればBランクの進化は有効ですが、それ以降はロスターが十分に大きくなり選択の余地が生まれるため、Bランクに素材を費やすよりもAランクやSランクの進化に素材を回す方が効率的になります。

## 進化とオフライン収入倍率

進化はBuild a Base and Stealのオフライン収入システムに直接影響を与えます。オフライン収入はペットの現在の基本レートに基づいて計算されるためです。エピックからレジェンダリーに進化させると基本レートが約50%上昇し、それはそのままオフライン収入への貢献度も50%増加することを意味します。ロスター全体の収入の10%を稼ぐペットであれば、その進化は全体のオフライン収入を5%増加させることになり、24時間の蓄積期間で見れば非常に大きな意味を持ちます。

複数の進化を重ねた場合の累積効果はさらに顕著です。5体のペットをエピックからレジェンダリーに進化させ、それぞれが全体の10%の収入に貢献している場合、オフライン収入は合計で25%増加します。1ヶ月の蓄積で見れば、これは莫大な追加キャッシュとなります。進化はアクティブな収入を増やすだけでなく、パッシブ収入を増やす手段でもあり、その利益は時間とともに複利で増えていきます。

### イベントに合わせた進化のタイミング

進化の最適なタイミングは、ガチャイベントの開催中です。ペットのドロップ率が上昇するため、進化素材を集めやすくなるからです。イベント中はボス戦も頻繁に発生するため、レア素材の供給も増加します。イベント中に進化を行うことで、通常時よりも少ない素材周回で素早く進化を完了させることができます。

ただし、ミシックへの最終進化については例外です。ミシックへの進化は、オフライン収入のキャップ（上限）に合わせて行うべきです。16〜20時間ほど放置してログオフする直前にレジェンダリーをミシックに進化させれば、その蓄積期間中ずっとミシック形態で収入を生成できます。逆にログイン直前に進化させるのは非効率です。蓄積期間のほとんどを以前の低いレアリティで過ごすことになってしまうからです。

## 進化の終盤戦（エンドゲーム）
