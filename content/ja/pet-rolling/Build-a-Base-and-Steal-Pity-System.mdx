Build a Base and Stealにおける天井（ピティ）システムは、ランダムロールシステムの下に用意されたセーフティネットです。すべてのロールにはレジェンダリーやミシカルのペットが出現する独立した確率がありますが、天井システムは、ランダムな結果に関わらず、十分な回数のロールを行った後に最終的に高ティアのペットを確実に獲得できることを保証します。天井システムは、進行が不可能に感じられるような極端な「爆死期間」を防ぐため、長期的なロールを持続可能なものにする要素です。このガイドでは、天井システムの仕組み、天井カウンターの追跡方法、そして最も効率的なロール戦略のために天井を活用する方法について説明します。

## 天井システムの仕組み

Build a Base and Stealの天井システムは、高ティアのペットが出現しないまま一定回数のロールを行った後に発動する確定ドロップメカニズムです。正確なしきい値はティアごとに異なりますが、一般的な構造は一貫しています。特定のティアのペットが出現しないまま一定回数ロールすると、次のロールでそのティア以上のペットが確定で出現します。

天井システムが存在する理由は2つあります。1つ目はプレイヤーの保護です。天井がなければ、プレイヤーは500回ロールしてもレジェンダリーを1匹も獲得できない可能性があり、これは多くのプレイヤーがゲームをやめてしまうほど不満が溜まる状況です。天井は、熱心なローラーにとっての最悪のシナリオが、一定回数のロール後に高ティアのドロップを確定で得られるように保証します。2つ目の理由はマネタイズです。天井は「ロールX回目でレジェンダリー確定」という明確なメッセージを生み出し、ランダムな結果が悪かったとしても、プレイヤーがしきい値に達するためにロールを続けるよう促します。

### 天井のしきい値

Build a Base and Stealにおける現在の天井のしきい値は以下の通りです。これらのしきい値は、対応するティアのペットを獲得するたびにリセットされ、すべてのロール活動を通じて累積されます。

**レア天井** - レアペットが出現しないまま25回ロールすると、次のロールでレア以上が確定します。
**エピック天井** - エピックペットが出現しないまま75回ロールすると、次のロールでエピック以上が確定します。
**レジェンダリー天井** - レジェンダリーペットが出現しないまま150回ロールすると、次のロールでレジェンダリー以上が確定します。
**ミシカル天井** - ミシカルペットが出現しないまま300回ロールすると、次のロールでミシカルが確定します。

しきい値は累積的です。つまり、エピック天井のしきい値に達する前にレジェンダリー天井のしきい値に達した場合、確定ロールはレジェンダリー（レジェンダリーはエピックより上のティアであるため、技術的にはエピックでもあります）を生成します。システムは、利用可能な最も高い確定枠を優先します。

また、しきい値はティア間で独立しています。これは、レジェンダリー天井カウンターとミシカル天井カウンターが異なる時点に存在できることを意味します。レジェンダリーが出現しないまま200回ロールしたものの、ちょうどミシカルをロールしたプレイヤーは、ミシカルのカウンターはリセットされますが、レジェンダリーのカウンターはリセットされず、次のロールでもレジェンダリー確定のままとなります。

### 天井カウンターの追跡

天井カウンターはロール画面で確認できますが、常に目立つように表示されているわけではありません。ほとんどのプラットフォームでは、ロールマシンにカーソルを合わせるか、ロール詳細パネルを開くことで、現在の天井ステータスを確認できます。表示には、各ティアの現在のカウントと、次の確定までのしきい値が表示されます。

一部のプレイヤーは、スプレッドシートやメモアプリなどの外部追跡ツールを使用して、ロールを記録し、手動で天井を追跡しています。手動のアプローチはより正確ですが、より多くの労力を必要とするため、大規模なロールセッションを計画しており、次の確定ドロップがいつ来るかを正確に知りたいプレイヤーにのみ価値があります。

ロールマシン自体は、ロールする前に天井のしきい値に達したことを教えてくれません。それは開発者が隠しておきたい情報を明かすことになるからです。天井のしきい値は、トリガーされる直前（しきい値のカウントに達した後のロール）にのみ表示されます。この設計は意図的なものであり、プレイヤーに確定がいつ発生するかを正確に伝えてしまうと、エンゲージメントを低下させるような形でロール行動が変わってしまうためです。

### 天井が戦略に与える影響

天井システムはロール戦略に大きな影響を与えます。天井を理解しているプレイヤーは、確定ドロップを中心にロールセッションを計画できます。つまり、多くの小さなセッションにロールを分散させるのではなく、しきい値に達するまで貯めておくということです。

最も一般的な天井を意識した戦略は、「貯めて一気に引く（save-and-burst）」アプローチです。プレイヤーはレジェンダリー天井のしきい値に達する（ただし超えない）のに十分なキャッシュが貯まるまでキャッシュを節約し、その後1回の大規模なロールセッションを行います。このセッションは確定レジェンダリーを利用するように構成されているため、ミシカルのしきい値を目指し続けたい場合を除き、確定ドロップが出た時点で終了します。

2つ目の戦略は、「コツコツ引く（steady-rolling）」アプローチです。プレイヤーは毎セッション少数のロールを行い、数週間のプレイを通じて徐々に天井カウンターを累積させていきます。コツコツ引くアプローチは、ロールあたりの効率は低くなりますが（確定枠が多くのセッションに分散するため）、一貫性がありリスクが低くなります（各セッションが小さいため）。

3つ目の戦略は、「イベントタイミング」アプローチです。プレイヤーはドロップ率がアップするイベントのために天井カウンターを温存し、イベント中に大規模なロールセッションを行います。アップしたドロップ率により、天井のしきい値に達する前に高ティアのペットが出現する確率が高まり、アップした確率で自然に出現しなかった場合でも、天井のしきい値によって高ティアのペットが確定します。

### リセットメカニズム

天井カウンターは、対応するティアのペットを獲得したときにリセットされます。レアペットを獲得すると、レア天井カウンターはゼロにリセットされます。エピックペットを獲得すると、エピック天井カウンターがリセットされます。レジェンダリーペットを獲得すると、レジェンダリー天井カウンターがリセットされます。ミシカルペットを獲得すると、ミシカル天井カウンターがリセットされます。

リセットは独立しているため、レジェンダリーを獲得してもレア天井カウンターはリセットされません。レア天井カウンターが20の状態でレジェンダリーをロールした場合、レジェンダリーはレジェンダリー天井カウンターをリセットしますが（アクティブだった場合）、レア天井カウンターは20のままです。次のロールでもレア天井はしきい値に近いままであり、その後すぐに確定レアを獲得できる可能性があります。

また、リセットは即座に行われます。つまり、リセットのトリガーとなったペット自体がカウントされます。遅延はなく、次のロールは新しいカウンターで開始されます。プレイヤーは、高ティアのペットを獲得した後に「公式に」カウンターをリセットするためにもう一度ロールを行う必要があると誤解することがありますが、リセットは高ティアのペットを獲得した瞬間に発生します。

## よくある天井のミス

最も一般的な天井のミスは、天井が特定のペットを保証するという思い込みです。天井は特定のペットではなく、ティアを保証します。確定レジェンダリーロールはレジェンダリーペットを生成しますが、どのレジェンダリーペットになるかはランダムに決定されます。特定のレジェンダリーを追い求めている場合、天井は役に立ちません。依然としてその特定のペットがドロップする必要があります。

2つ目のよくあるミスは、天井が高ティアのペットを獲得する唯一の方法であるという思い込みです。天井はセーフティネットであり、唯一の経路ではありません。ランダムなドロップ率によって高ティアのペットが定期的に出現するため、多くのプレイヤーは天井のしきい値に達するかなり前にレジェンダリーやミシカルのペットを獲得しています。天井は、最悪のシナリオがそれほど悪くならないようにするだけです。

3つ目のよくあるミスは、すべてのロールマシンで天井が共有されているという思い込みです。天井はマシンごとであり、グローバルではありません。ゲームに複数のロールマシンがある場合（一部の特別サーバーでは存在します）、天井カウンターはマシンごとに分かれています。あるマシンでロールしても、別のマシンの天井カウンターには影響しません。

## 天井効率の最大化

天井を使用する最も効率的な方法は、確定ドロップに最も近づいたときに大規模なロールセッションのタイミングを合わせることです。レジェンダリー天井カウンターが140の場合、確定まであと10ロールなので、少なくとも10ロールを含むロールセッションを計画する必要があります。しきい値を超えた余分なロールは通常のドロップ率になり、ロールあたりの効率が低下するため、セッションはしきい値を大幅に超えるべきではありません。

2つ目の効率的なヒントは、天井カウンターを定期的に監視し、カウンターの位置に基づいてロールの頻度を調整することです。カウンターが20の場合、確定からはほど遠いため、毎日の小さなロールで問題ありません。カウンターが130の場合、確定に近いため、より大きなセッションを行う価値があります。

3つ目の効率的なヒントは、天井とイベントのタイミングを組み合わせることです。ドロップ率がアップするイベントは、天井のしきい値に早く到達する確率も高めるため、イベント中は各ロールの実質的な価値が高くなります。イベント中の天井重視のセッションのためにキャッシュを節約することが、ゲーム内で最も効率的なロール戦略です。

天井システムの詳細に入る前に、目に見えるゲームを取り巻くメタゲームを理解する時間を取ってください。目に見えるゲームとは、ロール、建設、襲撃のループです。メタゲームとは、パッチサイクル、コミュニティの議論、取引経済、そして長期的な進行アークです。目に見えるゲームは、1回のセッションで30分間行うことです。メタゲームは、数週間から数ヶ月にわたって最適化するものです。最も成功しているプレイヤーは、両方のゲームを同等に真剣に扱い、真に大きな利益はメタゲームから得られることを理解しています。

2つ目は、ペットロールがゲームの他の部分とフィードバックループを持っているということです。基地が強くなれば防衛の成功率が上がり、それによって維持できるペットが増え、オフライン収入が増え、進行が早まり、さらに基地が強くなります。逆のフィードバックループも同様です。弱い基地はペットの喪失、進行の遅れ、防衛の弱体化につながります。序盤の決定は、どのループに入るかを決定するため、非常に大きな影響を与えます。

ゲームの天井システムエリアは、カジュアルプレイと競争プレイの違いが最も明確に現れる場所でもあります。カジュアルプレイヤーは天井システムをサブのアクティビティとして扱いますが、競争力のあるプレイヤーはそれを進行戦略の核心部分として扱います。同じアクティビティでも、意図のレベルが異なれば、劇的に異なる結果をもたらします。このセクションの内容は、経験豊富なプレイヤーが天井システムに適用している戦略的思考を共有することで、カジュアルから競争力のあるレベルへと一線を越える手助けをすることを目的としています。
