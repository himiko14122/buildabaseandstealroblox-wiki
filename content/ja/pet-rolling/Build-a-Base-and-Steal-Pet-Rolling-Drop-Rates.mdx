Build a Base and Stealにおけるペットの排出率は、ロール（ガチャ）を行うたびにどのレアリティのペットが手に入るかを決定する段階的な確率システムに従っています。このシステムを理解することは、ロール予算の計画、イベントボーナスの評価、そして浪費につながる認知的な罠を避けるために不可欠です。本ガイドでは、正確な確率構造、不運なプレイヤーを保護する天井（ピティ）メカニズム、そして賢いプレイヤーが実践している統計的な考え方を解説します。

## 6段階のレアリティ構造

Build a Base and Stealのペットには6段階のレアリティがあり、各段階にはロールごとに排出される確率が設定されています。レアリティは低い順に、コモン、アンコモン、レア、エピック、レジェンダリー、ミシックです。レアリティが高いほど収入倍率や取引価値も高くなるため、高レアリティのペットは非常に人気があります。以下の排出率は、イベント期間外の標準的なロールマシンに基づいています。

コモンペットは全ロールの約50〜55%を占めます。これらはあらゆるコレクションの基本であり、ベースとなる収入率を生み出し、より強力なコレクションを構築するための土台となります。アンコモンペットは約25〜28%を占めます。コモンよりも明らかに価値が高く、入手はそれほど難しくありません。週に100回ロールするプレイヤーは、通常12〜15匹のレアペットを獲得し、そのうちのいくつかは実際の取引価値を持つようになります。エピックペットの排出率は約5〜7%で、15〜20回程度のロールで1匹獲得できる計算です。レジェンダリーペットは約2〜3%、ミシックペットは最も希少で1%未満です。正確なパーセンテージはパッチによって変動する可能性がありますが、相対的な順序は安定しています。

### 天井（ピティ）システムの仕組み

純粋なランダムロールでは不運が続く可能性があるため、Build a Base and Stealには、一定回数ロールしても特定のレアリティが出なかった場合に、レア以上のペットを保証する天井システムが導入されています。標準的な天井のしきい値は50回です。つまり、50回連続でレア以上のペットが出なかった場合、51回目のロールでシステムが自動的にレア以上のペットを排出します。この保証は隠し機能ではなく、プレイヤーのエンゲージメントを維持し、ゲームが不公平であると感じさせないための公表されたメカニズムです。

天井システムにはレアリティ別の保証も含まれています。エピックが出ずに100回ロールするとエピックが保証され、レジェンダリーが出ずに250回ロールするとレジェンダリーが保証されます。これらの保証は独立しており、レアの天井に近づいたからといってエピックの天井に近づくわけではありません。

この構造は予算計画において重要です。なぜなら、ロールセッションにおける最悪のシナリオが制限されるからです。200回ロールしてもレアがゼロということはあり得ません。天井システムにより、最初の50回で少なくとも1匹のレア、100回で1匹のエピック、250回で1匹のレジェンダリーが保証されるからです。標準的なロール価格に基づけば、レジェンダリーを1匹獲得するために必要な最大費用を把握することができます。

### 期待値と分散

すべてのロールには、多くの回数を重ねた場合に得られる平均的なペットに基づく期待値があります。Build a Base and Stealにおける1回のロールの期待値は、おおよそコモンペットと同等であり、運が良ければレアリティがアップする可能性があります。100回ロールした場合の期待値は、コモン約55匹、アンコモン約27匹、レア約14匹、エピック約6匹、レジェンダリー2〜3匹、ミシック1匹未満となります。これらはあくまで平均であり、約束された結果ではありません。100回のロールセッションにおける実際の結果は、これらの数値から大きく逸脱することもあります。

分散こそが、ロールをエキサイティングかつ危険なものにしている要因です。プレイヤーが50回ロールして、コモン20匹、アンコモン20匹、レア5匹、エピック1匹、レジェンダリー0匹という、平均を大きく下回る結果になることもあります。どちらの結果も正常であり、ゲームが不正操作されていることを示すものではありません。分散は確率システムに参加するための代償であり、これを理解しているかどうかが、不運な時期を冷静に乗り切れるプレイヤーと、損失を取り戻そうとして破産するプレイヤーの分かれ道となります。

重要な統計的洞察は、サンプルサイズが大きくなるほど分散が小さくなるという点です。1,000回ロールすれば、結果は期待される分布に非常に近くなります。100回では適度に近く、10回では大きく異なる可能性があります。5〜10回のロールでレアペットを追い求めるセッションが信頼できないのはこのためであり、週や月単位でロールを分散させる長期的な計画が安定しているのはこのためです。

### イベントによる排出率ブースト

特別なイベント期間中、Build a Base and Stealは特定のペットやレアリティの排出率を上げることがあります。典型的なイベントでは、エピックの排出率が2倍になったり、特定の注目ペットの排出率が5倍になったりします。これらのブーストは通常期間限定であり、通常の天井システムと重複するため、対象のペットやレアリティを狙って集中投下することが可能です。レジェンダリーのために貯蓄していて、イベントでレジェンダリーの排出率が2倍になっているなら、今こそロール予算を使うべきタイミングです。ブースト中の各ロールの期待値は通常時よりも大幅に高く、同じ予算でより良い結果が得られます。

ただし、イベント限定の罠には注意してください。一部のイベントでは、宣伝されているブーストよりも排出率がはるかに低い「注目」ペットが登場したり、イベント専用通貨が必要になったりすることがあります。支出する前に必ずイベント詳細を読み、単なる広告上の倍率ではなく、実際の期待値を計算してください。0.1%から始まるペットへの5倍ブーストは、依然として0.5%に過ぎず、必ずしも良い取引とは言えません。

## 自身のロール履歴を読み解く

Build a Base and Stealのプレイヤーが身につけるべき最も価値のあるスキルは、自身のロール履歴を正確に読み解く能力です。多くのプレイヤーは、幸運なロールは記憶に残り、不運なロールは忘れられるため、自分がどれだけ幸運であるかを過大評価しがちです。200回ロールした後、7回目に出たレジェンダリーは覚えていても、その前の30匹のコモンは忘れてしまいます。このバイアスが「追いかけ」につながります。毎週、獲得したすべてのペットのレアリティを記録し、見直してください。1ヶ月後、実際の排出率が期待値に非常に近いこと、そして幸運や不運だと感じていたことはほとんどがノイズであったことに気づくでしょう。この洞察は大きな心理的優位性をもたらします。不運な時期にパニックになって支出することもなく、幸運な時期に浮かれて浪費することもなくなります。どちらの過剰反応も予算を破壊します。

Build a Base and Stealは、感情ではなく確率で考えるプレイヤーに報いるゲームです。排出率は、適度な勝利が継続的に発生し、時折大きな勝利が得られるように設計されています。この設計を内面化し、それに応じてロールするプレイヤーこそが、時間をかけて最強のコレクションを築くことができます。感情に流され、「次は出るはずだ」や「今は波が来ている」と信じて追いかけるプレイヤーは、予算を使い果たしてゲームを辞めていくことになります。

### 追加の戦略的コンテキスト

このセクションでは、経験豊富なプレイヤーがペットの排出率に関して上記の戦略を適用する際に考慮する実践的なポイントを解説します。ここでの内容は、コミュニティによる検証、ハイレベルなプレイパターンの観察、およびペットロールメカニズムと他のゲームシステム間の相互作用に基づいています。数百時間のプレイから得られる文脈的な洞察を、一度の読書で吸収できるように凝縮しました。

真剣なプレイヤーにとっての出発点は、このゲームが単なる時間の投資よりも、熟慮された情報に基づいた決定に報いることを認識することです。次の行動を30分かけて考えたプレイヤーは、3時間ランダムにクリックし続けたプレイヤーよりも早く成長します。その理由は、Build a Base and Stealが相互に関連するメカニズムのシステムであり、あらゆる行動がシステム全体に波及するからです。ロール戦略の変更は拠点に影響を与え、それが防御に影響し、レイド収入に影響し、次のロール予算に影響を与えます。

ペットロールと取引の関係は、初心者が見落としがちなポイントです。行う取引は拠点、防御、そしてロールの選択肢に影響を与えます。拠点に最適なペットが、取引資産としてはより高い価値を持つこともあります。自分が弱いと思っているペットが、他のプレイヤーのコレクションボーナスを完成させるピースであり、プレミアムな価値を持つこともあります。取引の考え方はポートフォリオ思考です。すべてのペットは個人的な資産であると同時に潜在的な取引チップであり、その価値はより広い市場の文脈に依存します。

最後に、ペットロールは激しさよりも一貫性に報います。毎日30分ログインして計画的にプレイするプレイヤーは、週に1回5時間ログインしてその時々の気分でプレイするプレイヤーよりも早く成長します。理由は複利システムと同じです。小さく定期的な行動は時間をかけて大きな利益を生み出しますが、散発的な大きな行動は、複利効果のない散発的な結果しか生み出しません。

### ペット排出率は取引経済とどのように相互作用しますか？

取引とペット排出率は互いに強化し合います。ペット排出率は取引可能な資産を生み出します。この原則を自動的に適用できるプレイヤーは、そうでないプレイヤーよりも30〜50%速く成長する傾向があります。なぜなら、この原則がすべての行動における熟慮のプロセスをショートカットするからです。

### ペット排出率を狙うのに最適な時間帯はありますか？

最適な時間は、あなたのタイムゾーンとアクティブなイベントスケジュールによって異なります。この概念を一貫して適用すれば、最新のメタ情報を追いかけるプレイヤーを追い抜くことができます。なぜなら、メタが変化しても基礎となる確率は安定しているからです。

### 1セッションあたりのペット排出率ロール予算はどれくらいが適切ですか？

ペット排出率ロールの適切な予算は、1日の現金収入の20〜30%です。コミュニティ内のペットロールの達人は皆このメンタルモデルを共有しており、これを採用することは個人の成長曲線を加速させる最も早い方法の一つです。

### 初心者にとって最も重要なペット排出率の概念は何ですか？

重要な原則は、ペット排出率は複利であるということです。小さく一貫した行動は、時折行う大きな行動に勝ります。この原則を意思決定の指針にすれば、パッチごとにゲームがリセットされたかのように振る舞うプレイヤーよりも、はるかに早く適応できるようになるでしょう。
