Build a Base and Stealの経済は、ゲーム内のあらゆるメカニズムを結びつける目に見えないシステムです。ガチャを回せばペットが手に入り、ペットがキャッシュを生み出し、そのキャッシュで壁を強化し、壁がペットを守り、守られたペットがさらにキャッシュを生み出します。ゲーム内で行うすべての行動は、限られたリソースをこのループのどこに投資するかという決断です。このループを理解していない初心者は、複利効果を生むことなく浪費を繰り返し、毎日プレイしているのになぜか貧しいままという状況に陥ります。本ガイドでは、この経済エンジンを完全に解明し、キャッシュフローの仕組みと、最初のセッションから役立つ投資判断のメンタルモデルを解説します。

## 3つの通貨レイヤー

Build a Base and Stealでは技術的には1つの通貨（キャッシュ）しか使用しませんが、初心者の方は混同しがちな3つの異なる役割があります。1つ目は「運用キャッシュ」で、ガチャ、壁、トラップ、装備などに今すぐ使える手元の現金です。2つ目は「生産キャッシュ」で、オンライン中にペットが生成しているキャッシュです。3つ目は「パッシブキャッシュ」で、オフライン中にペットが蓄積するキャッシュです。これら3つのレイヤーを混同することが、初心者が陥る最大のミスです。運用キャッシュを、生産キャッシュやパッシブキャッシュが存在しないかのように使い果たしてしまい、いざという時に資金不足を感じるのです。

運用キャッシュは最も目に見えるものですが、実際には最も小さなレイヤーに過ぎません。初心者は1,000の運用キャッシュを持ってリッチな気分になるかもしれませんが、同じ1,000に加え、1分あたり200の生産キャッシュがあり、8時間のオフライン蓄積があるプレイヤーの方がはるかに強力な立場にあります。運用キャッシュは今すぐ使えるもの、生産キャッシュはセッション終了時に手に入るもの、パッシブキャッシュは明日ログインした時に手に入るものです。これらすべてが重要であり、健全なアカウントはこれら3つを同時に管理しています。

### キャッシュフローのループ

Build a Base and Stealのキャッシュフローは一方向に流れます。ガチャでペットを入手し、ペットがキャッシュを生み、キャッシュで壁やトラップを強化し、壁やトラップがペットを守り、守られたペットがさらにキャッシュを生むという流れです。このループは自己強化型ですが、中断させないことが条件です。ガチャに全額使ってしまう初心者は、新しいペットを守る壁がないためループを断ち切ってしまいます。壁に全額使ってしまう初心者は、収入源となる新しいペットがいないためループを断ち切ってしまいます。キャッシュをすべて貯め込む初心者は、既存の収入源が守られていないか、停滞しているためループを断ち切ってしまいます。

重要なのは、このループには「速度」があり、ループを壊さずにその速度を最大化することが目標だということです。速度は、ペットを増やす（収入源を増やす）、既存のペットをレベルアップさせる（ペットあたりの収入を増やす）、コレクションボーナスを完了させる（乗算的な収入ブースト）ことで向上します。逆に、レイドでペットを失う（収入源の減少）、ペットのレベル上げを怠る（収入の停滞）、収入に繋がらない方法でキャッシュを使う（収入を生まない装飾的なアップグレード）ことで速度は低下します。

### ペットコレクションの複利効果

Build a Base and Stealにおけるペットコレクションは、複利システムです。最初に手に入れた10匹のペットは少額の収入を生みますが、次の10匹でその収入はおよそ倍になります。さらに次の10匹で、また倍になります。これは、ペットの収入がペットの数に対してほぼ線形であり、線形な成長が時間とともに指数関数的な曲線を描くためです。ペットコレクションを20匹から40匹に倍増させたプレイヤーの収入はおよそ2倍になり、40匹から80匹に再び倍増させれば、さらに2倍になります。

この複利効果により、初期のガチャへの投資は時間とともに大きな利益をもたらします。1秒間に1キャッシュを生むコモンペットは単体では無価値に思えますが、50匹いれば1秒間に50キャッシュを生み出し、数時間ごとに壁を1つ設置できるパッシブ収入になります。同じ論理がレアやレジェンダリーペットにも当てはまります。レジェンダリーを狙うのは高く感じますが、3〜4匹手に入れてしまえば、その収入のおかげでガチャのコストは些細なものに感じられるはずです。

### 防御のコスト

Build a Base and Stealにおいて、防御は無料ではありません。壁の建設、トラップの設置にはキャッシュがかかり、強力なものほどコストは高くなります。防御コストはガチャに次ぐゲーム内最大のキャッシュ消費源であり、初心者が最も過小評価しがちな部分です。層状の壁、複数のトラップ、保管庫を備えた完全に要塞化された拠点は、小さなペットコレクション以上のコストがかかることがあり、さらにレイドで壁が損傷すれば修理が必要になるため、コストは継続的に発生します。

経済的な観点から言えば、防御は「収入に対する税金」です。政府がサービス提供のために所得に課税するように、あなたの拠点はペットの収入に課税して保護を維持します。問題は「税金を払うかどうか」ではなく、「いかに効率的に払うか」です。適切に設計された拠点は、適度なコストで強力な保護を提供します。設計の悪い拠点は、高いコストで弱い保護しか提供しません。この差が、持続可能な成長と緩やかな衰退の分かれ道となります。

### 3つのバケツのバランス

標準的な予算配分は、ガチャに50%、防御に30%、予備費に20%です。これはコミュニティで最も検証されているバランスポイントです。これが唯一の正解ではありませんが、多くのプレイヤーにとって最も状況に適した配分です。50%のガチャ投資で収入エンジンを成長させ、30%の防御投資でそれを守り、20%の予備費で壁の突破や急なイベントなどの予期せぬ事態に備えます。

この配分はアカウントの成熟度に応じて調整すべきです。拠点が完全に無防備な初心者は、40/40/20の配分を検討してください。無防備な拠点は、一度の突破ですべてを失うリスクがあるからです。防御が確立された経験豊富なプレイヤーは、ドロップ率がブーストされるイベント期間中には60/30/10で運用することもあります。イベント中はガチャの価値が高まり、壁が強固であれば予備費を減らすリスクも低くなるからです。重要なのは、配分を宗教的に守ることではなく、ループを回し続けることです。

## オフライン収入の役割

オフライン収入は、Build a Base and Stealにおける経済のイコライザー（平準化装置）です。1日30分しかプレイできないプレイヤーでも、5時間プレイするプレイヤーと競うことができます。オフライン収入システムが24時間365日稼働しているからです。8時間のオフライン上限があるため、数日間放置してシステムを悪用することはできませんが、カジュアルなプレイヤーでも毎日意味のあるキャッシュを蓄積できます。1日1回ログインして8時間分のオフライン収入を受け取り、1時間プレイしてログアウトするカジュアルプレイヤーは、1日4時間プレイするハードコアプレイヤーとほぼ同じペースで進行できます。セッションごとのペースが遅いだけです。

経済的な観点からは、アクティブな収入効率ではなく、オフライン収入の効率を最大化するように拠点を設計すべきです。アクティブ収入はプレイ中に目にするものですが、オフライン収入は戻ってきた時に受け取るものです。どちらも同じ計算式を使用するため、アクティブ収入をブーストするペットやアップグレードはオフライン収入もブーストします。しかし、オフライン収入はキーボードの前にいる必要がないため、より信頼性が高いのです。オフライン収入に最適化された拠点は、あなたがそこにいようがいまいが成長し続ける拠点です。

## よくある経済的なミス

Build a Base and Stealで最も多い経済的なミスは「オールイン・ガチャ」です。レジェンダリーを狙って、全キャッシュを一度のガチャセッションに投じる行為です。期待値は他のガチャセッションと同じですが、分散（振れ幅）が非常に大きく、失敗した時の代償が大きすぎます。オールインしてレジェンダリーを引いたプレイヤーは最高の気分でしょうが、何も引けなかったプレイヤーは数日分の進捗を失います。データ上、後者の方が圧倒的に多いのが現実です。

2番目に多いミスは「防御の放置」です。ガチャとペットコレクションの拡大に集中するあまり、なぜ頻繁にレイドされるのか不思議に思うケースです。解決策は機械的です。ガチャを回す前に、毎回必ず壁かトラップを1つ設置してください。たとえわずかでも常に防御を改善するという規律は、時間をかけて積み重なり、ガチャしかしないプレイヤーの拠点よりもはるかにレイドされにくい拠点を作り上げます。

3番目に多いミスは「予備費の放置」です。キャッシュをすべてガチャと防御に使い果たし、緊急時のための資金を残さないケースです。予備費があれば、レイド後の壁の修理、突然のイベントへの対応、ガチャの好調時の追い込みが可能になります。予備費がゼロのプレイヤーは一度の悪いレイドで深刻な後退を余儀なくされますが、20%の予備費を持つプレイヤーは打撃を吸収し、プレイを続けることができます。

## よくある質問

### 1セッションあたり、経済システムのためにどれくらいのキャッシュを予算化すべきですか？

日次収入の20〜30%を経済システム（投資）に割り当ててください。このセクションから一つだけ持ち帰るとすれば、この原則を覚えておいてください。「具体的な行動は変わっても、根底にある論理は変わらない」ということです。

### 新規プレイヤーにとって最も重要な経済の概念は何ですか？

核心となる考え方は、経済システムはゲームの他の部分と相互に関連しており、単独の活動ではないということです。この洞察がカジュアルプレイヤーと熱心なやり込み勢を分けます。毎月のリーダーボードのリセット時に、常に同じ名前がトップに現れるのはこのためです。

### この戦略の結果が出るまでどれくらいかかりますか？

ほとんどのプレイヤーは、一貫して適用してから1〜2週間以内に意味のある結果を実感します。この原則を理解すれば、特定のガイドを読む必要はなくなり、自分自身の戦略を生成できるようになります。その原則が、あなたの特定の状況においてどの行動が理にかなっているかを教えてくれるからです。

### この戦略はソロプレイヤーとチームの両方で機能しますか？

はい。この戦略はデフォルトでソロプレイヤー向けに記述されています。コミュニティ内の経済に精通したマスターたちは皆このメンタルモデルを共有しており、それを採用することは個人の成長曲線を加速させる最も速い方法の一つです。

### アップデート後に戦略が機能しなくなった場合はどうすればよいですか？

関連するシステムに変更がないかパッチノートを確認してください。この原則を指針として判断を下せば、パッチを完全なリセットと捉えるプレイヤーよりも早く適応できるはずです。
