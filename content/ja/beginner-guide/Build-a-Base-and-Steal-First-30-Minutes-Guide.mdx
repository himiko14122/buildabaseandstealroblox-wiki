Build a Base and Stealにおける最初の30分間は、その後に続くすべてを決定づけます。この分刻みの攻略ガイドでは、新規プレイヤーが正確に何をすべきか、何を無視すべきか、そしてほとんどの初心者がロード画面が終わる前に自らの進行を妨げてしまうポイントを解説します。この計画に従えば、最初のセッションを終える頃には、機能的なベース、健全なペットのラインナップ、そして次の3日間のプレイに向けた明確なロードマップが手に入っているでしょう。

## 0分〜5分：スポーンと調査

Build a Base and Stealに初めてロードされたら、ローリングマシンは無視してください。手持ちの初期資金をすぐに使いたいという衝動を抑えましょう。ほとんどの初心者は、最初の60秒間で軍資金の80%を使い果たし、なぜ壁1枚すら買えないのかと頭を抱えることになります。代わりに、深呼吸をしてマップを見渡してください。自分の区画の外周を歩いてみましょう。ローリングマシン、ビルドメニュー、ギアショップ、そしてレイドポータルの場所を確認します。1ユニットも消費する前にすべての場所を把握しておくことで、後で何時間も迷うのを防ぐことができます。

Build a Base and Stealのスポーンエリアでは、常に少額の初期キャッシュが与えられます。これは現在のサーバー価格にもよりますが、およそ5〜10回分のロールに相当します。これは棚ぼたの利益ではなく、テストです。ゲームは、あなたが計画を立てるまでガチャの衝動を抑えられるかどうかを試しているのです。このテストに合格したプレイヤーは、機能する経済体制を整えてセッションを開始できます。不合格だったプレイヤーは、すでにローリングマシンに借金を抱えた状態でセッションを開始し、次の2時間をその穴埋めに費やすことになります。

### 最初にビルドメニューを開く

キャッシュを1ユニットでも使う前に、ビルドメニューを開き、最も基本的な壁と最も基本的な床のコストを確認してください。このシンプルな行動には2つの意味があります。第一に、Build a Base and Stealではサーバーの稼働時間やプレイヤー数に基づいて価格が調整されることがあるため、現在のサーバーにおける実際の防御コストを把握できます。第二に、「すべてのロールには壁のコストという明確な対価がある」という意識を持つことができます。1回のロールが壁半枚分に相当すると分かれば、より賢明な判断ができるようになります。

また、ビルドメニューからはトラップや障害物のシステムも確認できます。まだ何も配置する必要はありませんが、何が利用可能かを知っておくことで、適当に壁を建てて神頼みするのではなく、内側から外側へとベースを設計できるようになります。メニューを最初に読むプレイヤーは意図を持ったベースを構築できますが、このステップをスキップするプレイヤーは、レンガの山を落として砦と呼んでいるようなベースを作ってしまいます。

## 5分〜15分：最初の壁と最初のロール

メニューの感覚がつかめたら、最初の壁を配置しましょう。ベース全体ではなく、壁を1枚だけです。将来のベースの入り口となる場所を示すために、区画の自然な境界線に沿って、意図的な場所に1枚だけ配置します。この最初の壁を配置する行為は、心理的に2つの目標を達成します。自分は単なるローラー（ガチャを引くだけの人）ではなくビルダーであるという意識を持たせること、そしてその後に決定するすべてのキャッシュの使い方の具体的な基準点となることです。

ここで最初のロールを行います。1回だけです。アニメーションを見て、獲得したレア度を記録し、収入率を確認してください。このロールはレジェンダリーを当てるためのものではなく、フィードバックの仕組みを理解するためのものです。ペットはどのように現れるのか？どこに行くのか？収入率はどうやって確認するのか？これらのメカニズムは10時間プレイした後には当たり前に感じられますが、最初のセッションでは混乱しやすく、混乱は誤った判断を招きます。8分目にフィードバックの仕組みを理解したプレイヤーは、20分目にはより良いロールの判断ができるようになります。

### ペットを配置してから、壁を配置する

順序が重要です。まず保護したいエリアの内側に最初のペットを配置し、その後、それを囲むように壁を拡張します。これはほとんどの初心者が行うこととは逆であり、その差は積み重なっていきます。ペットを先に配置すると、その後に建てるすべての壁に明確な目的が生まれます。壁を先に建ててしまうと、何を保護しているのか分からないままレンガを積み上げることになります。前者のアプローチは整理されたベースを生み出し、後者のアプローチは混沌を生み出します。

## 15分〜25分：土台の構築

ここでさらに3〜5回ロールを行いますが、それは基本的な壁を配置した後に限ります。具体的な回数はサーバーのロール価格によりますが、原則は決まっています。ペットのラインナップを増やす前に、少なくともシンプルな囲いを作っておく必要があります。初心者にありがちなミスは、10回ロールしてコモンを5体手に入れ、その後で壁を買うお金がないことに気づくことです。彼らは、いつ盗まれてもおかしくない、ほとんど収入を生まない低ティアのペットの山を無防備に抱えることになります。

最初のセッションの後半15分を使って、シンプルですが完全な外周を構築しましょう。要塞である必要はなく、3面または4面を囲み、管理された入り口を1つ設けるだけで十分です。キャッシュが余っている場合は、入り口の近くに障害物や低コストのトラップを1つ追加します。この最小限のレイアウトは想像以上に安価で、構築にかかる時間は10分未満であり、ほとんどのカジュアルなレイドを防ぐことができます。Build a Base and Stealのレイダーは簡単なターゲットを探しているため、半分完成したベースであっても、むき出しのペットよりははるかに魅力が薄れます。

### 実践における50/30/20ルール

クラシックな初心者向けの予算配分は、キャッシュの50%をロールに、30%を防御に、20%を貯蓄に割り当てます。最初の30分間において、これは初期資金をほぼその割合で消費することを意味します。1,000キャッシュで開始した場合、ロールに500、壁と障害物に300、そして200を手元に残すことになります。25分目が終わるまでに、4〜6体のペット、基本的な外周、そして1回の緊急事態に対応できるだけの十分なキャッシュリザーブを確保しておく必要があります。

このリザーブ（予備資金）は、初心者が考えている以上に重要です。より経験豊富なプレイヤーがサーバーに参加してベースを探り始めた場合、リザーブがあれば最も弱い壁を補強したり、緊急のトラップを配置したりできます。脅威が現れなければ、そのリザーブはオフライン中の蓄積の一部として2回目のセッションに引き継がれます。Build a Base and Stealにおいて、少額のキャッシュリザーブを保持することが、限界までロールに費やすことよりも悪い選択肢になるシナリオは存在しません。

## 25分〜30分：戦略的なログアウト

ここに、ほとんどの初心者が決して学ばないコツがあります。どのようにログアウトするかが、どのようにプレイするかと同じくらい重要であるということです。Build a Base and Stealのオフライン収入システムは、ペットのコレクションと不在時間に基づいて収益を計算しますが、あなたがアクティブに防御していないことも前提としています。最も賢明な最初のセッションは、ベースが合理的に防御され、ペットが合理的に価値を持っている状態でログアウトすることです。

大きなロールを行った直後にログアウトしてはいけません。新しいペットが無防備であり、その周囲に防御をまだ配置していないからです。建設の途中でログアウトしてはいけません。半分完成した壁は完成した壁よりも弱く、再ログインしたときに突破されている可能性があるからです。最適なログアウトのタイミングは、目に見える収入をすべて回収し、ベースが安定した構成になり、戻ってきたときのために少額のキャッシュリザーブが用意されている状態です。

### 2日間の計画

最初のセッションは、次にすべき明確なステップを決めて終了するように計画しましょう。ログアウトする前に、戻ってきたときに最初に行うアクションを決めておきます。壁の2層目の完成でしょうか？特定のペットを狙ったロールセッションでしょうか？それとも、オープンなベースを建てている隣人へのレイドでしょうか？具体的な計画を持っておくことで、多くの初心者が陥る「ログインしたものの、画面を見つめたまま何をすべきか決めるのに20分を無駄にする」という2回目のセッションの麻痺状態を防ぐことができます。

Build a Base and Stealで最も成功している新規プレイヤーは、最初の30分間をスプリント（全力疾走）ではなく、土台として捉えています。彼らはゆっくりと構築し、慎重にロールし、意図を持ってログアウトします。最初のロールの熱狂に初期資金をすべて使い果たすせっかちなプレイヤーは、ほぼ例外なく最初の1日以内にゼロから作り直すことになります。彼らは、このゲームの経済が焦りに罰を与え、計画に報酬を与えることを身をもって学ぶのです。

## 初回セッションで避けるべきよくある罠

最もよくある罠は、「オールイン（全賭け）ロール」です。プレイヤーが参加し、3回目のロールで運良くエピックやレジェンダリーを獲得すると、さらなる獲得を目指して追いかけてしまいます。リザーブをすべて使い果たし、何も得られず、価値のあるペット1体と防御ゼロの状態でログアウトします。次にログインしたときには、そのレジェンダリーは消え去り、追いかけた結果として残るものは何もありません。解決策は機械的です。どんなに調子が良いと感じても、1回のセッションでロールにキャッシュの50%以上を費やしてはいけません。

2つ目の罠は、「空っぽのベース」です。プレイヤーがロールだけに集中し、30体のペットコレクションを構築しながら、壁を1枚も配置しないケースです。彼らは自分が金持ちになった気分でログアウトしますが、戻ってきたときには区画が空っぽになっています。どんなに素晴らしいコレクションであっても、5秒で盗まれてしまっては価値がありません。防御はオプション（選択肢）ではなく、ゲームの残りの部分に参加するための入場料です。

3つ目の罠は、「レイドの失敗」です。新規プレイヤーはレイドポータルを見て、盗むことが成長への最も手っ取り早い方法だと考えます。彼らは高レベルのベースに対してギア予算を使い果たし、レイドに敗北し、何も残らない結果になります。Build a Base and Stealにおける最初のレイドの成功は、常に自分よりも明らかに弱いベースをターゲットにすべきです。勝利は自信と小さな初期資金をもたらします。敗北は、新規プレイヤーをセッション丸ごと後退させます。

## 最初のセッションの後にすべきこと

最初の30分間は、機能するベース、小さなペットのラインナップ、キャッシュリザーブ、そして計画を持って終了します。次のセッションでは、以下の3つのことに順番に焦点を当てる必要があります：防御の2層目の完成、ターゲットを絞ったロールによるペットコレクションの拡大、そして最初の本格的なレイドへの挑戦です。セッション2の終わりまでに、ベースらしいベース、10〜15体のペットのラインナップ、そして少なくとも1回のレイド成功実績を確保しておく必要があります。

Build a Base and Stealは、階層的に考えるプレイヤーに報酬を与えます。レイヤー1は、最初の30分間で構築する土台です。レイヤー2は、最初の1日で行う拡張です。レイヤー3は、最初の1週間で行う最適化です。各レイヤーは前のレイヤーの上に構築されるため、レイヤーをスキップすると次のレイヤーが崩壊します。最初の30分間をマスターすれば、ゲームの残りの部分が開かれます。そこを台無しにすると、ゲームは回復のための絶え間ない苦闘になってしまいます。

## よくある質問

### この戦略の効果が出るまで、どのくらいの時間がかかりますか？

ほとんどのプレイヤーは、一貫して適用してから1〜2週間以内に有意義な結果を実感します。この原則を内面化することが、成長が頭打ちになるプレイヤーと登り続けるプレイヤーを分けるポイントであり、その差はわずか数週間でリーダーボードの順位に現れます。

### この戦略はソロプレイヤーとチームプレイヤーの両方に有効ですか？

はい。この戦略はデフォルトとしてソロプレイヤー向けに説明されています。この原則を自然に適用できるようになったプレイヤーは、すべてのアクションについて意識的に考える必要があるプレイヤーよりも30〜50%早く進行する傾向があります。なぜなら、この原則があらゆる行動の検討段階をショートカットするからです。

### パッチ後に戦略が機能しなくなった場合はどうすればよいですか？

関連するシステムの変更についてパッチノートを確認してください。これを戦術的な提案としてではなく、基礎的なルールとして捉えることで、小さく一貫した行動の積み重ね効果が数週間以内に進行状況として目に見えるようになります。

### このトピックに関するより詳細な情報はどこで入手できますか？

最初の30分間のアップデートについては、コミュニティWiki、公式Discord、および開発者ブログを確認してください。Discordでの真剣な「最初の30分間」の議論では、最もアクティブなプレイヤーたちが自らの経験を通じてすべて同じ結論に達しているため、この原則が繰り返し語られているのを目にするでしょう。

### 最初の30分間は取引経済とどのように相互作用しますか？

最初の30分間と取引は深く結びついています。最初の30分間の成果が、取引の選択肢を左右します。この原則を一度身につければ、特定のガイドを読むのをやめて独自の戦略を生み出すことができます。なぜなら、この原則があなたの特定の状況においてどのアクションが合理的であるかを教えてくれるからです。
