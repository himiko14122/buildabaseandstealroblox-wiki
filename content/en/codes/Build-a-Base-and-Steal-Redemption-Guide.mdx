## Where to Find the Code Redemption Menu

Build a Base and Steal hides the code entry point inside the main menu, not on the spawn screen where most beginners instinctively look. When you first join a server, do not click on the rolling machine or the build menu. Instead, look for the **menu button** in the corner of your screen, usually marked with three horizontal lines, a gear icon, or the word "Codes." Tapping that button opens a side panel that contains several tabs: Codes, Settings, Leaderboard, and Help. The Codes tab is where every active promo code is redeemed.

If you are playing on a mobile device or tablet, the menu may collapse into a small icon at the top of your screen. Tap once to expand it, then look for the gift box icon labeled "Codes." Roblox mobile interfaces change frequently, so if the icon has moved, scroll the menu horizontally until you find it. The codes tab is always present; the developers do not remove it during updates because it is part of the live-ops pipeline that drives player engagement.

### Confirming the Codes Tab Loaded

Once you tap the Codes tab, you should see a text input field, a "Redeem" button, and a banner showing your current unclaimed rewards. If the field is missing, you have opened the wrong tab. Close the menu and look for the gift icon again. The codes tab is sometimes grouped with daily login rewards, so be careful not to confuse the two. Daily login rewards are claimed automatically by playing each day, while code rewards require a manual string entry.

## Entering Codes Correctly

Type the code into the text field exactly as it appears in the official list. Build a Base and Steal codes are case-sensitive, meaning uppercase and lowercase letters matter. A code written as "FREEPET" will not work if you enter "freepet" or "FreePet." The most common redemption error in the game is a single misplaced character, usually a capital letter, a missing digit, or an extra space. Copying and pasting codes from our active list eliminates this problem entirely, but if you must type the code manually, double-check every character before tapping Redeem.

After typing the code, tap the Redeem button. If the code is active, you will see a confirmation banner listing the rewards you just received, including the amount of cash, the number of free rolls, or any pets included. The rewards are delivered to your in-game wallet and pet storage instantly; you do not need to relog or restart the game. If the confirmation banner does not appear, the code was not accepted, and you need to troubleshoot (see below).

### Why Codes Sometimes Fail

There are four common reasons a code fails to redeem in Build a Base and Steal. First, the code has expired. Developers cycle out older codes when they release new ones, and expired codes are silently rejected. Always check the active list on our wiki before entering a code, especially if you found the code from an older YouTube video or a screenshot. Second, you mistyped the code. Even one wrong character invalidates the entry. Third, the code is region-locked. Some promotional codes only work in specific countries due to licensing restrictions. Fourth, you have already redeemed the code on your account. Most codes are one-time per account, so attempting to redeem the same code twice returns an error.

If you are certain the code is active and you typed it correctly, try restarting the game and re-entering the code. Roblox sometimes caches old server data, and a clean reconnect forces the client to pull fresh code lists from the developer's backend. If the code still fails after a restart, post in the community Discord and the developers or moderators will usually clarify whether the code is bugged or restricted.

## What to Do With Code Rewards

Once you have redeemed your codes, the question becomes how to spend the rewards. Most players instinctively rush to the rolling machine, but this is not always optimal.
