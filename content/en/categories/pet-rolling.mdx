## 🎲 Understanding Pet Rolling Mechanics

### How Rolling Works
Pet rolling is the **primary method** for acquiring new pets in Build a Base and Steal. Each roll operates on a calculated probability system with defined rarity tiers and drop rates.

### Core Rolling Principles
- **Currency Cost**: Each roll consumes a specific amount of in-game cash


- **Independent Probability**: Each roll is calculated independently with no memory


- **Rarity Tiers**: Pets come in six distinct rarity levels


- **Market Influence**: Rolling costs can fluctuate based on game economy

### The Rolling Process
1. **Pay the Cost**: Spend the required currency for one roll


2. **Random Generation**: The system calculates outcome based on probability


3. **Rarity Determination**: Drop rate determines which rarity tier you receive


4. **Pet Assignment**: Random pet from the determined rarity tier


5. **Inventory Addition**: New pet is added to your collection
